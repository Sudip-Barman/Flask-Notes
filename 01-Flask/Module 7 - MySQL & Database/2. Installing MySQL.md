
To use MySQL with Flask, we first need a **MySQL Server** running on our computer.

There are several ways to install it. For learning Flask + MySQL on Windows, the easiest approach is usually **MySQL Installer**.

---

## 1. What do we need?

For a basic Flask + MySQL setup:

```
Python
   │
   ▼
Flask
   │
   ▼
MySQL Connector / SQLAlchemy
   │
   ▼
MySQL Server
```

You **do not need all MySQL tools** just to run a Flask application.

The important component is:

> **MySQL Server**

You can then use a GUI such as MySQL Workbench to manage it.

---

# 2. Download MySQL

Go to the official MySQL website:

[MySQL Downloads](https://dev.mysql.com/downloads/?utm_source=chatgpt.com)

Look for **MySQL Community Server** or the **MySQL Installer for Windows**.

For Windows beginners, the MySQL Installer is convenient because it can install the server and supporting tools together.

---

# 3. MySQL Installer Options

During installation, you may see options such as:

```
Developer Default
Server Only
Client Only
Full
Custom
```

For learning Flask + MySQL, **Developer Default** is a convenient choice because it provides the server plus common development tools.

If you want a minimal installation, **Server Only** is also sufficient for the database server.

---

# 4. MySQL Server

The most important component is:

```
MySQL Server
```

This is the actual database server.

After installation, your computer will have something conceptually like:

```
Computer
│
└── MySQL Server
      │
      ├── Database 1
      ├── Database 2
      └── Database 3
```

Your Flask application will connect to this server.

---

# 5. MySQL Workbench

You may also install:

> **MySQL Workbench**

Workbench provides a graphical interface for managing MySQL.

Instead of writing everything in a terminal, you can visually:

- Create databases
- Create tables
- Run SQL
- View table data
- Manage users
- Inspect database structure

The relationship is:

```
MySQL Server
     ▲
     │
     │ connection
     │
MySQL Workbench
```

Workbench is **not the database itself**.

It's a tool for interacting with the MySQL Server.

---

# 6. Configuration

During installation, MySQL asks you to configure the server.

For a normal local development setup, you'll encounter settings such as:

```
Config Type
Port
Authentication
Root Password
Windows Service
```

For most beginners, the default values are fine unless you have a specific reason to change them.

---

# 7. MySQL Port

MySQL commonly uses:

```
3306
```

The port is how applications identify the MySQL service on your computer.

Your Flask application will eventually connect using something conceptually like:

```
Host:     localhost
Port:     3306
Username: root
Password: ********
Database: my_database
```

Think of it as:

```
localhost:3306
     │
     ▼
MySQL Server
```

---

# 8. Root User

During installation you'll normally create/set a password for the MySQL `root` account.

For example:

```
Username: root
Password: your_password
```

`root` has very high privileges.

For learning on your own computer, you may use it while experimenting.

For production applications, however, it's better to create a dedicated database user with only the permissions the application needs.

---

# 9. Windows Service

MySQL can be installed as a **Windows service**.

This allows Windows to manage the MySQL server.

Conceptually:

```
Windows
   │
   └── MySQL Service
           │
           ▼
      MySQL Server
```

You can then start or stop MySQL through Windows' service management tools.

---

# 10. Check Whether MySQL Is Running

After installation, open a terminal and try:

```
mysql --version
```

If MySQL is correctly available in your PATH, you'll see something similar to:

```
mysql  Ver 8.x.x ...
```

The exact version will depend on what you installed.

---

# 11. Connecting to MySQL

You can connect from the command line:

```
mysql -u root -p
```

You'll then be asked for your password:

```
Enter password:
```

After successful login, you'll see a MySQL prompt:

```
mysql>
```

Now you're communicating directly with the MySQL server.

Try:

```
SHOW DATABASES;
```

You should see databases such as:

```
information_schema
mysql
performance_schema
sys
```

These are system databases created by MySQL.

---

# 12. Create Your First Database

Let's create a database for practice:

```
CREATE DATABASE flask_learning;
```

Then:

```
SHOW DATABASES;
```

You should now see:

```
flask_learning
```

Select it:

```
USE flask_learning;
```

You'll get something like:

```
Database changed
```

Now you're working inside:

```
flask_learning
```

---

# 13. Test With a Table

Create a simple table:

```
CREATE TABLE students (
    id INT,
    name VARCHAR(100),
    age INT
);
```

Check it:

```
SHOW TABLES;
```

You should see:

```
students
```

Insert some data:

```
INSERT INTO students (id, name, age)
VALUES (1, 'Alice', 20);
```

Then:

```
SELECT * FROM students;
```

Result:

```
+----+-------+-----+
| id | name  | age |
+----+-------+-----+
|  1 | Alice |  20 |
+----+-------+-----+
```

🎉 Your MySQL installation is working.

---

# 14. MySQL Installation vs Flask Connection

These are **two different steps**.

### Step 1: Install MySQL

```
Computer
   ↓
MySQL Server
   ↓
Database
```

### Step 2: Connect Flask to MySQL

Later:

```
Browser
   ↓
Flask
   ↓
SQLAlchemy
   ↓
MySQL
   ↓
Database
```

We will **not connect Flask yet**.

That belongs to **Module 8: Flask + MySQL**.

---

# 15. Important Terms

|Term|Meaning|
|---|---|
|**MySQL Server**|Software that manages MySQL databases|
|**Database**|Collection of related data|
|**Table**|Structure that stores data in rows and columns|
|**SQL**|Language used to communicate with the database|
|**MySQL Workbench**|GUI tool for working with MySQL|
|**Port 3306**|Default MySQL network port|
|**root**|Administrative MySQL account|
|**localhost**|Your own computer|
