
**MySQL is a Relational Database Management System (RDBMS)** used to **store, organize, retrieve, and manage data**.

In simple words:

> **MySQL is software that manages databases.**

For example, suppose you build a website where users can register. You need to store:

```
ID
Name
Email
Password
```

MySQL can store that information in a table:

```
users
┌────┬────────┬───────────────────┐
│ ID │ Name   │ Email             │
├────┼────────┼───────────────────┤
│ 1  │ Alice  │ alice@example.com │
│ 2  │ Bob    │ bob@example.com   │
└────┴────────┴───────────────────┘
```

### MySQL's role

Think of your Flask application like this:

```
             User
              │
              ▼
           Browser
              │
              │ HTTP
              ▼
            Flask
              │
              │ SQL
              ▼
            MySQL
              │
              ▼
          Database
              │
              ▼
            Tables
              │
              ▼
             Data
```

Flask handles the **application logic**, while MySQL handles the **data storage and management**.

---

## MySQL vs Database

These two terms are easy to confuse.

### Database

A **database** is the organized collection of data.

Example:

```
school
```

containing:

```
students
teachers
courses
```

### MySQL

**MySQL is the software that manages those databases.**

```
MySQL
│
├── school
│   ├── students
│   ├── teachers
│   └── courses
│
└── shop
    ├── products
    └── orders
```

---

## What can MySQL do?

MySQL allows you to:

- Create databases
- Create tables
- Store data
- Retrieve data
- Update data
- Delete data
- Search/filter data
- Connect related tables
- Control access to data
- Handle transactions

You communicate with MySQL using **SQL**.

For example:

```
SELECT * FROM students;
```

means:

> "Give me all the students."

And:

```
INSERT INTO students (name, age)
VALUES ('Alice', 20);
```

means:

> "Add Alice to the students table."

---

## MySQL vs SQL

Remember this distinction:

```
SQL
↓
Language used to communicate with databases

MySQL
↓
Database management software that understands SQL
```

So you **write SQL commands**, and **MySQL executes them**.

### One-line definition for your notes

> **MySQL is an open-source relational database management system (RDBMS) that uses SQL to store, organize, retrieve, and manage structured data.**
