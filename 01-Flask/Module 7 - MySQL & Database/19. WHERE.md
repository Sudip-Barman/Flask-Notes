
`WHERE` is used in SQL to **filter rows**.

In simple words:

> **WHERE = Decide which rows should be selected, updated, or deleted.**

This is one of the most important SQL clauses because you'll use it constantly.

---

# 1. The Basic Idea

Suppose we have:

```
students

┌────┬─────────┬─────┬────────────┐
│ id │ name    │ age │ city       │
├────┼─────────┼─────┼────────────┤
│ 1  │ Alice   │ 20  │ Kolkata    │
│ 2  │ Bob     │ 21  │ Delhi      │
│ 3  │ Charlie │ 19  │ Mumbai     │
│ 4  │ David   │ 22  │ Kolkata    │
└────┴─────────┴─────┴────────────┘
```

If you say:

> "Show me students who are older than 20."

You use:

```
SELECT *
FROM students
WHERE age > 20;
```

`WHERE` filters the rows:

```
All rows
   ↓
WHERE age > 20
   ↓
Bob
David
```

---

# 2. WHERE With SELECT

The most common use is:

```
SELECT *
FROM students
WHERE condition;
```

Example:

```
SELECT *
FROM students
WHERE age = 20;
```

Result:

```
┌────┬───────┬─────┬─────────┐
│ id │ name  │ age │ city    │
├────┼───────┼─────┼─────────┤
│ 1  │ Alice │ 20  │ Kolkata │
└────┴───────┴─────┴─────────┘
```

The condition:

```
age = 20
```

means:

> Only return rows where age is 20.

---

# 3. WHERE With UPDATE

`WHERE` isn't only for `SELECT`.

You can use it with `UPDATE`:

```
UPDATE students
SET age = 21
WHERE id = 1;
```

Meaning:

```
Find row where id = 1
       ↓
Change its age to 21
```

Without `WHERE`:

```
UPDATE students
SET age = 21;
```

every student's age would be changed.

---

# 4. WHERE With DELETE

You can also use it with `DELETE`:

```
DELETE FROM students
WHERE id = 3;
```

Meaning:

```
Find row where id = 3
       ↓
Delete that row
```

Without `WHERE`:

```
DELETE FROM students;
```

all rows are deleted.

---

# 5. Comparison Operators

`WHERE` commonly uses comparison operators.

|Operator|Meaning|
|---|---|
|`=`|Equal to|
|`!=`|Not equal to|
|`<>`|Not equal to|
|`>`|Greater than|
|`<`|Less than|
|`>=`|Greater than or equal to|
|`<=`|Less than or equal to|

Let's see them.

---

# 6. Equal To `=`

```
SELECT *
FROM students
WHERE age = 20;
```

Means:

> Find students whose age is exactly 20.

---

# 7. Not Equal `!=`

```
SELECT *
FROM students
WHERE age != 20;
```

Means:

> Find students whose age is not 20.

You can also use:

```
WHERE age <> 20;
```

Both mean "not equal" in MySQL.

---

# 8. Greater Than `>`

```
SELECT *
FROM students
WHERE age > 20;
```

Result:

```
Bob     → 21
David   → 22
```

`>` means:

> Greater than.

---

# 9. Less Than `<`

```
SELECT *
FROM students
WHERE age < 20;
```

Result:

```
Charlie → 19
```

`<` means:

> Less than.

---

# 10. Greater Than or Equal `>=`

```
SELECT *
FROM students
WHERE age >= 20;
```

This includes 20:

```
20 ✓
21 ✓
22 ✓
19 ✗
```

---

# 11. Less Than or Equal `<=`

```
SELECT *
FROM students
WHERE age <= 20;
```

This includes 20:

```
19 ✓
20 ✓
21 ✗
22 ✗
```

---

# 12. WHERE With Text

You can compare text values too.

```
SELECT *
FROM students
WHERE city = 'Kolkata';
```

Result:

```
Alice
David
```

Notice the quotes:

```
'Kolkata'
```

Text values are normally written inside quotes.

---

# 13. WHERE With AND

`AND` allows you to combine conditions.

For example:

> Find students older than 20 **and** from Kolkata.

```
SELECT *
FROM students
WHERE age > 20
AND city = 'Kolkata';
```

Think:

```
age > 20
    AND
city = Kolkata
```

Both must be true.

For our table:

```
David
```

matches both conditions.

---

# 14. WHERE With OR

`OR` means at least one condition must be true.

For example:

```
SELECT *
FROM students
WHERE city = 'Kolkata'
OR city = 'Delhi';
```

Result:

```
Alice
Bob
David
```

Because:

```
Alice   → Kolkata ✓
Bob     → Delhi   ✓
Charlie → Mumbai  ✗
David   → Kolkata ✓
```

---

# 15. AND vs OR

This is worth remembering:

```
AND
 ↓
Everything must match

OR
 ↓
At least one must match
```

Example:

```
WHERE age > 20 AND city = 'Kolkata'
```

means:

```
age > 20
AND
city = Kolkata
```

while:

```
WHERE age > 20 OR city = 'Kolkata'
```

means:

```
age > 20
OR
city = Kolkata
```

These can produce very different results.

---

# 16. Using Parentheses

When combining `AND` and `OR`, parentheses make your intention clear.

Example:

```
SELECT *
FROM students
WHERE (city = 'Kolkata' OR city = 'Delhi')
AND age >= 20;
```

Read it as:

```
        ┌─ Kolkata
City ───┤
        └─ Delhi
             ↓
         AND age >= 20
```

Parentheses help control how conditions are grouped.

---

# 17. WHERE With IN

Suppose you want students from:

```
Kolkata
Delhi
Mumbai
```

You could write:

```
SELECT *
FROM students
WHERE city = 'Kolkata'
OR city = 'Delhi'
OR city = 'Mumbai';
```

But that's long.

You can use `IN`:

```
SELECT *
FROM students
WHERE city IN ('Kolkata', 'Delhi', 'Mumbai');
```

This means:

> Is the city one of these values?

It's essentially a convenient way to express multiple equality checks.

---

# 18. WHERE With NOT IN

You can also exclude values:

```
SELECT *
FROM students
WHERE city NOT IN ('Kolkata', 'Delhi');
```

Meaning:

> Find students whose city is neither Kolkata nor Delhi.

Charlie from Mumbai would match.

---

# 19. WHERE With BETWEEN

Suppose you want students whose age is between 20 and 22.

```
SELECT *
FROM students
WHERE age BETWEEN 20 AND 22;
```

This includes the boundaries:

```
20 ✓
21 ✓
22 ✓
19 ✗
```

So:

```
BETWEEN 20 AND 22
        ↓
20 through 22
```

---

# 20. BETWEEN With Numbers

For example:

```
SELECT *
FROM products
WHERE price BETWEEN 500 AND 1000;
```

This finds products whose price is within that range, including the endpoints.

---

# 21. WHERE With LIKE

`LIKE` is used for **pattern matching**.

Suppose:

```
Alice
Bob
Charlie
David
```

You want names beginning with `A`.

```
SELECT *
FROM students
WHERE name LIKE 'A%';
```

Result:

```
Alice
```

Here:

```
%
```

means:

> Any number of characters.

So:

```
A%
```

means:

```
A + anything after it
```

---

# 22. LIKE With `%`

Examples:

### Starts with A

```
WHERE name LIKE 'A%'
```

Matches:

```
Alice
Andrew
Alex
```

### Ends with e

```
WHERE name LIKE '%e'
```

Could match:

```
Alice
Charlie
```

### Contains "li"

```
WHERE name LIKE '%li%'
```

Could match:

```
Alice
Charlie
```

The `%` is extremely useful for searching text patterns.

---

# 23. LIKE With `_`

`_` represents **exactly one character**.

For example:

```
WHERE name LIKE 'A_ice'
```

means:

```
A
↓
one character
↓
ice
```

So:

```
Alice
```

matches.

Think:

```
% → any number of characters
_ → exactly one character
```

---

# 24. WHERE With NULL

This is an important special case.

Suppose:

```
id | name  | city
---+-------+-------
1  | Alice | Kolkata
2  | Bob   | NULL
```

You should **not** write:

```
WHERE city = NULL;
```

Instead use:

```
WHERE city IS NULL;
```

To find rows where a value exists:

```
WHERE city IS NOT NULL;
```

So:

```
IS NULL
    ↓
Find missing values

IS NOT NULL
    ↓
Find existing values
```

---

# 25. Why `= NULL` Doesn't Work

`NULL` isn't an ordinary value like:

```
10
20
'Kolkata'
```

It represents the absence or unknown nature of a value.

Therefore SQL uses special operators:

```
IS NULL
IS NOT NULL
```

rather than:

```
= NULL
!= NULL
```

This is a common SQL beginner mistake.

---

# 26. WHERE With Dates

Suppose we have:

```
orders

id | order_date
---+------------
1  | 2026-08-01
2  | 2026-08-15
3  | 2026-09-01
```

You could search for a specific date:

```
SELECT *
FROM orders
WHERE order_date = '2026-08-15';
```

Or use a range:

```
SELECT *
FROM orders
WHERE order_date >= '2026-08-01'
AND order_date <= '2026-08-31';
```

This is commonly used when filtering records by date.

---

# 27. WHERE and UPDATE

Now you can understand this more deeply:

```
UPDATE students
SET age = age + 1
WHERE city = 'Kolkata';
```

Break it down:

```
UPDATE students
      ↓
Which table?

SET age = age + 1
      ↓
What change?

WHERE city = 'Kolkata'
      ↓
Which rows?
```

So only Kolkata students have their age increased.

---

# 28. WHERE and DELETE

Similarly:

```
DELETE FROM students
WHERE age < 20;
```

Breakdown:

```
DELETE FROM students
      ↓
Which table?

WHERE age < 20
      ↓
Which rows?
```

Only students younger than 20 are removed.

---

# 29. WHERE and SELECT

And:

```
SELECT name, age
FROM students
WHERE age >= 20;
```

means:

```
SELECT name, age
      ↓
What information?

FROM students
      ↓
Which table?

WHERE age >= 20
      ↓
Which rows?
```

This pattern appears everywhere in SQL.

---

# 30. WHERE Is a Filter

The easiest mental model is:

> **WHERE = Filter**

Imagine the table is a large bucket of rows:

```
All rows
──────────────────
Alice
Bob
Charlie
David
Emma
Frank
Grace
──────────────────
        ↓
    WHERE age > 20
        ↓
──────────────────
Bob
David
Emma
──────────────────
```

The `WHERE` clause acts like a **filter gate**.

Only rows satisfying the condition pass through.

---

# 31. WHERE Does Not Change Data

With `SELECT`:

```
SELECT *
FROM students
WHERE age > 20;
```

`WHERE` only decides which rows to **show**.

It doesn't change the table.

But with `UPDATE`:

```
UPDATE students
SET age = 25
WHERE age > 20;
```

`WHERE` decides which rows to **change**.

With `DELETE`:

```
DELETE FROM students
WHERE age > 20;
```

`WHERE` decides which rows to **remove**.

So:

```
WHERE itself doesn't modify data.

It identifies/filter rows.
```

---

# 32. Very Important Pattern

You'll see this pattern again and again:

```
SELECT ...
FROM ...
WHERE ...;
```

```
UPDATE ...
SET ...
WHERE ...;
```

```
DELETE FROM ...
WHERE ...;
```

The `WHERE` clause answers:

> **"Which rows?"**

That's the key idea.

---

# 33. Common Mistakes

### Mistake 1: Forgetting quotes around strings

❌

```
WHERE city = Kolkata;
```

✅

```
WHERE city = 'Kolkata';
```

---

### Mistake 2: Using `= NULL`

❌

```
WHERE city = NULL;
```

✅

```
WHERE city IS NULL;
```

---

### Mistake 3: Forgetting WHERE in UPDATE

⚠️

```
UPDATE students
SET age = 20;
```

This updates every row.

---

### Mistake 4: Forgetting WHERE in DELETE

⚠️

```
DELETE FROM students;
```

This deletes every row.

# 34. Quick Reference

|Condition|Meaning|
|---|---|
|`age = 20`|Age is 20|
|`age != 20`|Age isn't 20|
|`age > 20`|Age is greater than 20|
|`age < 20`|Age is less than 20|
|`age >= 20`|Age is 20 or greater|
|`age <= 20`|Age is 20 or less|
|`city = 'Delhi'`|City is Delhi|
|`city IN ('Delhi','Mumbai')`|City is Delhi or Mumbai|
|`city NOT IN ('Delhi','Mumbai')`|City isn't Delhi or Mumbai|
|`age BETWEEN 20 AND 25`|Age is from 20 to 25|
|`name LIKE 'A%'`|Name starts with A|
|`name LIKE '%a'`|Name ends with a|
|`name LIKE '%an%'`|Name contains "an"|
|`city IS NULL`|City has no value|
|`city IS NOT NULL`|City has a value|

# 35. The One Thing to Remember

If you remember only one thing from this topic, remember:

```
WHERE = Which rows?
```

For example:

```
SELECT *
FROM students
WHERE age > 20;
```

```
SELECT → What data?
FROM   → Which table?
WHERE  → Which rows?
```

And:

```
UPDATE students
SET age = 21
WHERE id = 1;
```

```
UPDATE → Which table?
SET    → What change?
WHERE  → Which rows?
```

And:

```
DELETE FROM students
WHERE id = 1;
```

```
DELETE → Remove
FROM   → From which table?
WHERE  → Which rows?
```

That's the heart of `WHERE`. 🎯
