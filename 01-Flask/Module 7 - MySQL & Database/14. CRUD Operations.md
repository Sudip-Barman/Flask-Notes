**CRUD** is a very important concept in databases.

CRUD stands for:

```
C → Create
R → Read
U → Update
D → Delete
```

These are the **four basic operations** we perform on data in a database.

---

# 1. The Big Picture

Suppose we have a `students` table:

```
students

┌────┬─────────┬─────┐
│ id │ name    │ age │
├────┼─────────┼─────┤
│ 1  │ Alice   │ 20  │
│ 2  │ Bob     │ 21  │
└────┴─────────┴─────┘
```

We can:

```
CREATE → Add a new student
READ   → Get student information
UPDATE → Change student information
DELETE → Remove a student
```

These four operations make up **CRUD**.

---

# 2. CRUD and SQL

CRUD maps to common SQL commands like this:

|CRUD|Meaning|SQL|
|---|---|---|
|**C**|Create data|`INSERT`|
|**R**|Read data|`SELECT`|
|**U**|Update data|`UPDATE`|
|**D**|Delete data|`DELETE`|

So remember:

```
CREATE → INSERT
READ   → SELECT
UPDATE → UPDATE
DELETE → DELETE
```

This mapping is extremely important.

---

# 3. CREATE

Create means:

> **Add new data to the database.**

In SQL, we use:

```
INSERT
```

Suppose our table is:

```
CREATE TABLE students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),
    age INT
);
```

To add a student:

```
INSERT INTO students (name, age)
VALUES ('Alice', 20);
```

The table becomes:

```
┌────┬───────┬─────┐
│ id │ name  │ age │
├────┼───────┼─────┤
│ 1  │ Alice │ 20  │
└────┴───────┴─────┘
```

Notice that we didn't provide `id`.

Because:

```
id INT AUTO_INCREMENT PRIMARY KEY
```

MySQL generates it automatically.

---

# 4. Insert Multiple Rows

You can insert multiple records with one statement:

```
INSERT INTO students (name, age)
VALUES
    ('Alice', 20),
    ('Bob', 21),
    ('Charlie', 19);
```

Result:

```
┌────┬─────────┬─────┐
│ id │ name    │ age │
├────┼─────────┼─────┤
│ 1  │ Alice   │ 20  │
│ 2  │ Bob     │ 21  │
│ 3  │ Charlie │ 19  │
└────┴─────────┴─────┘
```

---

# 5. READ

Read means:

> **Retrieve existing data from the database.**

In SQL, we use:

```
SELECT
```

For example:

```
SELECT * FROM students;
```

Result:

```
┌────┬─────────┬─────┐
│ id │ name    │ age │
├────┼─────────┼─────┤
│ 1  │ Alice   │ 20  │
│ 2  │ Bob     │ 21  │
│ 3  │ Charlie │ 19  │
└────┴─────────┴─────┘
```

The `*` means:

> Select all columns.

---

# 6. Selecting Specific Columns

Instead of:

```
SELECT * FROM students;
```

we can specify columns:

```
SELECT name, age
FROM students;
```

Result:

```
┌─────────┬─────┐
│ name    │ age │
├─────────┼─────┤
│ Alice   │ 20  │
│ Bob     │ 21  │
│ Charlie │ 19  │
└─────────┴─────┘
```

---

# 7. Reading a Specific Row

We can use `WHERE`.

```
SELECT *
FROM students
WHERE id = 2;
```

Result:

```
┌────┬──────┬─────┐
│ id │ name │ age │
├────┼──────┼─────┤
│ 2  │ Bob  │ 21  │
└────┴──────┴─────┘
```

So:

```
SELECT
   ↓
Read data

WHERE
   ↓
Choose which data to read
```

We'll study `WHERE` in detail later.

---

# 8. UPDATE

Update means:

> **Change existing data.**

In SQL:

```
UPDATE
```

Suppose Bob is now 22.

We can write:

```
UPDATE students
SET age = 22
WHERE id = 2;
```

Before:

```
2 | Bob | 21
```

After:

```
2 | Bob | 22
```

---

# 9. Why WHERE Is Extremely Important With UPDATE

Look at this:

```
UPDATE students
SET age = 22;
```

There is **no `WHERE` condition**.

That means:

> Change the age of **every row** to 22.

You might end up with:

```
Alice   → 22
Bob     → 22
Charlie → 22
```

😬

Usually, that's not what you want.

So when updating a specific record, use:

```
UPDATE students
SET age = 22
WHERE id = 2;
```

---

# 10. Updating Multiple Columns

You can change multiple columns:

```
UPDATE students
SET
    name = 'Robert',
    age = 22
WHERE id = 2;
```

Now:

```
Before:
2 | Bob | 21

After:
2 | Robert | 22
```

---

# 11. DELETE

Delete means:

> **Remove data from the database.**

In SQL:

```
DELETE
```

For example:

```
DELETE FROM students
WHERE id = 3;
```

Before:

```
1 | Alice
2 | Bob
3 | Charlie
```

After:

```
1 | Alice
2 | Bob
```

Charlie has been removed.

---

# 12. Be Careful With DELETE

This is dangerous:

```
DELETE FROM students;
```

There is no `WHERE`.

That means:

> Delete **all rows** from the table.

So:

```
Before:

Alice
Bob
Charlie
David

        ↓

DELETE FROM students;

        ↓

After:

(empty)
```

💀

The table still exists, but its rows have been deleted.

# 13. CRUD in One Example

Let's perform all four operations.

### Create

```
INSERT INTO students (name, age)
VALUES ('Alice', 20);
```

```
C → Add Alice
```

### Read

```
SELECT *
FROM students;
```

```
R → Get Alice
```

### Update

```
UPDATE students
SET age = 21
WHERE id = 1;
```

```
U → Change Alice's age
```

### Delete

```
DELETE FROM students
WHERE id = 1;
```

```
D → Remove Alice
```

So:

```
       CRUD
        │
 ┌──────┼──────┐
 │      │      │
 C      R      U      D
 │      │      │      │
INSERT SELECT UPDATE DELETE
```

# 16. CRUD vs HTTP Methods

You'll also see CRUD when learning REST APIs.

|Read|`SELECT`|`GET`|
|Update|`UPDATE`|`PUT` / `PATCH`|
|Delete|`DELETE`|`DELETE`|

For example:

```

 ↓

 ↓

 ↓

```

# 17. CRUD Doesn't Mean "CREATE TABLE"

One small but important distinction.

In CRUD:

```
C = Create data
```

It usually means **creating records**, not creating the database table itself.

For example:

```
CREATE TABLE students (...);
```

is a **DDL** operation, not the "C" in CRUD.

CRUD's Create is generally:

```
INSERT INTO students (...);
```

So:

```
CREATE TABLE
→ Create database structure

INSERT
→ Create/add a record
```

---

# 18. CRUD and Rows

Think of CRUD as manipulating **records/rows**:

```
Table
│
├── Row 1
├── Row 2
└── Row 3
```

Then:

```
CREATE
→ Add Row 4

READ
→ Get Row 2

UPDATE
→ Modify Row 2

DELETE
→ Remove Row 2
```

This is the core idea.

# 19. Complete Example

Let's create a table:

```
CREATE TABLE students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    age INT
);
```

### C: Create

```
INSERT INTO students (name, age)
VALUES ('Alice', 20);
```

### R: Read

```
SELECT *
FROM students;
```

### U: Update

```
UPDATE students
SET age = 21
WHERE id = 1;
```

### D: Delete

```
DELETE FROM students
WHERE id = 1;
```

That's a complete CRUD cycle.
