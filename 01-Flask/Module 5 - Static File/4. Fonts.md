Fonts in Flask are handled just like CSS, JavaScript, and images:

> **Flask serves the font file as a static file, while the browser loads and uses the font.**

Flask itself does not apply the font. CSS tells the browser which font to use.

---

# 1. Where Do Fonts Go?

Put font files inside:

```
static/fonts/
```

For example:

```
project/
│
├── app.py
│
├── templates/
│   └── home.html
│
└── static/
    ├── css/
    │   └── style.css
    │
    ├── js/
    │   └── script.js
    │
    ├── images/
    │   └── logo.png
    │
    └── fonts/
        ├── MyFont-Regular.woff2
        └── MyFont-Bold.woff2
```

Common font formats are:

```
.woff2
.woff
.ttf
.otf
```

For websites, **WOFF2 is generally the preferred format** because it is optimized for web delivery.

---

# 2. Why Do We Need `@font-face`?

Normally CSS can use a font already available on the user's computer:

```
body {
    font-family: Arial;
}
```

But what if you want to use your own font?

The user's computer may not have it.

That's where:

```
@font-face
```

comes in.

It tells the browser:

> "Here is the font file. Load it and make it available under this font name."

---

# 3. Basic `@font-face`

Suppose:

```
static/
├── css/
│   └── style.css
│
└── fonts/
    └── MyFont-Regular.woff2
```

In `style.css`:

```
@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont-Regular.woff2") format("woff2");
}
```

Now the browser knows about:

```
MyFont
```

You can use it:

```
body {
    font-family: "MyFont", sans-serif;
}
```

---

# 4. Understanding the Path

This is important.

Your CSS is:

```
static/css/style.css
```

Your font is:

```
static/fonts/MyFont-Regular.woff2
```

From:

```
static/css/
```

go up one level:

```
../
```

Then:

```
fonts/
```

So:

```
url("../fonts/MyFont-Regular.woff2")
```

points to:

```
static/fonts/MyFont-Regular.woff2
```

The relationship is:

```
static/
│
├── css/
│   └── style.css
│        │
│        └── ../
│              ↓
└── fonts/
    └── MyFont-Regular.woff2
```

# 5. Complete Example

### Project

```
project/
│
├── app.py
│
├── templates/
│   └── home.html
│
└── static/
    ├── css/
    │   └── style.css
    │
    └── fonts/
        └── MyFont-Regular.woff2
```

### `style.css`

```
@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont-Regular.woff2") format("woff2");
}

body {
    font-family: "MyFont", sans-serif;
}
```

### `home.html`

```
<!DOCTYPE html>

<html>

<head>

    <title>Custom Font</title>

    <link
        rel="stylesheet"
        href="{{ url_for('static', filename='css/style.css') }}"
    >

</head>

<body>

    <h1>Hello Flask</h1>

    <p>This page uses a custom font.</p>

</body>

</html>
```

That's enough to load a local font.

# 6. Why Isn't `url_for()` Used for the Font?

You might wonder why we use:

```
url("../fonts/MyFont-Regular.woff2")
```

instead of:

```
{{ url_for(...) }}
```

The reason is that:

```
style.css
```

is itself a static file.

Flask normally does not process it through Jinja2.

Therefore this:

```
src: url("{{ url_for('static', filename='fonts/MyFont.woff2') }}");
```

is **not the normal approach** for a static CSS file.

Instead, use a relative path:

```
src: url("../fonts/MyFont.woff2");
```

# 7. Font Weight

Real fonts often have multiple versions:

```
MyFont-Regular.woff2
MyFont-Bold.woff2
MyFont-Light.woff2
```

You can define each one separately.

```
@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont-Regular.woff2") format("woff2");
    font-weight: 400;
}

@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont-Bold.woff2") format("woff2");
    font-weight: 700;
}
```

Then:

```
body {
    font-family: "MyFont", sans-serif;
    font-weight: 400;
}

h1 {
    font-family: "MyFont", sans-serif;
    font-weight: 700;
}
```

The browser knows:

```
400 → Regular
700 → Bold
```

---

# 8. Font Styles

You can also define italic fonts.

For example:

```
static/fonts/
├── MyFont-Regular.woff2
└── MyFont-Italic.woff2
```

CSS:

```
@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont-Regular.woff2") format("woff2");
    font-weight: 400;
    font-style: normal;
}

@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont-Italic.woff2") format("woff2");
    font-weight: 400;
    font-style: italic;
}
```

Then:

```
p {
    font-family: "MyFont", sans-serif;
}
```

If you use:

```
<p>
    Normal text
</p>

<p>
    <em>Italic text</em>
</p>
```

the browser can select the appropriate font file.

# 9. Multiple Font Weights

A more complete setup could look like:

```
static/fonts/
├── MyFont-Light.woff2
├── MyFont-Regular.woff2
├── MyFont-Medium.woff2
├── MyFont-SemiBold.woff2
└── MyFont-Bold.woff2
```

Then:

```
@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont-Light.woff2") format("woff2");
    font-weight: 300;
}

@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont-Regular.woff2") format("woff2");
    font-weight: 400;
}

@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont-Medium.woff2") format("woff2");
    font-weight: 500;
}

@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont-SemiBold.woff2") format("woff2");
    font-weight: 600;
}

@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont-Bold.woff2") format("woff2");
    font-weight: 700;
}
```

Now you can use:

```
h1 {
    font-weight: 700;
}

h2 {
    font-weight: 600;
}

p {
    font-weight: 400;
}
```

The browser chooses the corresponding font file.

# 11. Providing a Fallback

Always consider a fallback:

```
body {
    font-family: "MyFont", Arial, sans-serif;
}
```

This means:

```
Try MyFont
    ↓
if unavailable
    ↓
Try Arial
    ↓
if unavailable
    ↓
Use generic sans-serif
```

This is called a **font stack**.

# 12. Font Loading Flow

Suppose:

```
static/fonts/MyFont.woff2
```

is referenced from:

```
static/css/style.css
```

The browser roughly does:

```
Browser
   │
   │ GET /
   ▼
Flask
   │
   ▼
HTML
   │
   ▼
Browser
   │
   │ GET /static/css/style.css
   ▼
Flask
   │
   ▼
CSS
   │
   │ browser sees @font-face
   ▼
Browser
   │
   │ GET /static/fonts/MyFont.woff2
   ▼
Flask
   │
   ▼
Font
   │
   ▼
Browser renders text
```

So the font is actually another HTTP resource.

# 13. Font 404 Error

Suppose the browser requests:

```
/static/fonts/MyFont.woff2
```

and gets:

```
404 Not Found
```

Check your project:

```
static/
├── css/
│   └── style.css
│
└── fonts/
    └── MyFont.woff2
```

and your CSS:

```
@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont.woff2") format("woff2");
}
```

A common mistake is:

```
src: url("fonts/MyFont.woff2");
```

From `static/css/`, that would incorrectly look for:

```
static/css/fonts/MyFont.woff2
```

Instead:

```
../fonts/MyFont.woff2
```

goes to:

```
static/fonts/MyFont.woff2
```

# 14. Font Not Applying

Suppose the font loads successfully but the text still looks wrong.

Check:

### Font family name

You defined:

```
font-family: "MyFont";
```

Then use exactly:

```
body {
    font-family: "MyFont";
}
```

### Weight

If you only have:

```
font-weight: 400;
```

but request:

```
font-weight: 900;
```

the browser may have to synthesize or choose another available weight.

### Browser console

Open:

```
F12
↓
Console
```

### Network

Open:

```
F12
↓
Network
↓
Font
```

Check whether the font file returns:

```
200
```

or:

```
404
```

# 15. Fonts With Template Inheritance

Your font normally belongs in the CSS loaded by `base.html`.

For example:

```
templates/
├── base.html
├── home.html
└── about.html

static/
├── css/
│   └── style.css
└── fonts/
    └── MyFont.woff2
```

`base.html`:

```
<link
    rel="stylesheet"
    href="{{ url_for('static', filename='css/style.css') }}"
>
```

`style.css`:

```
@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont.woff2") format("woff2");
}

body {
    font-family: "MyFont", sans-serif;
}
```

Every page extending `base.html` gets the font.

# 16. Google Fonts vs Local Fonts

There are two common ways to use fonts.

### Local font

You download the font and store it:

```
static/fonts/
```

Then:

```
@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont.woff2") format("woff2");
}
```

### External font service

You can load fonts from an external provider.

For example, a provider may give you:

```
<link ...>
```

or:

```
@import ...;
```

Then the browser downloads the font from that external service rather than your Flask server.

For a Flask learning project, understanding local fonts is more important because it teaches you how static assets actually work.

---

# 17. Local Font vs External Font

|Local Font|External Font|
|---|---|
|Stored in your project|Stored on external server|
|Flask serves it|External service serves it|
|More control|Easier setup|
|Can work without external font service|Requires external connection|
|Adds files to project|Less local storage|

# 18. Font Files Are Static Assets

At this point you can see the common pattern:

```
static/
│
├── css/
│   └── style.css
│
├── js/
│   └── script.js
│
├── images/
│   └── logo.png
│
└── fonts/
    └── MyFont.woff2
```

Flask serves all of them.

```
Flask
  │
  ├── CSS
  ├── JavaScript
  ├── Images
  └── Fonts
       ↓
    Browser
```

The browser then decides what to do with each resource.

---

# 19. Important Distinction

Remember the division of responsibility:

```
Flask
│
└── Serves the font file

CSS
│
└── Tells browser which font to use

Browser
│
└── Loads font and renders text
```

Flask doesn't understand typography.

It simply delivers the file.
