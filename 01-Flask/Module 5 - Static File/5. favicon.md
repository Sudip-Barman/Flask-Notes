A **favicon** is the small icon associated with a website.

You usually see it:

- In the browser tab
- In bookmarks
- In browser history
- Sometimes next to saved shortcuts

For example:

```
┌─────────────────────────────────────┐
│ 🌐 My Website  ×  │ +              │
└─────────────────────────────────────┘
```

The small icon before **My Website** is the favicon.

---

# 1. Where Does the Favicon Go?

Since a favicon is a static asset, you can place it inside `static`.

A clean structure is:

```
project/
│
├── app.py
│
├── templates/
│   └── base.html
│
└── static/
    ├── css/
    ├── js/
    ├── images/
    ├── fonts/
    │
    └── favicon.ico
```

You can also organize it as:

```
static/images/favicon.ico
```

Both approaches work.

For a simple Flask project, keeping it directly inside `static` is convenient.

---

# 2. Adding a Favicon

Suppose you have:

```
static/favicon.ico
```

In your HTML `<head>`:

```
<link
    rel="icon"
    href="{{ url_for('static', filename='favicon.ico') }}"
>
```

Complete example:

```
<!DOCTYPE html>

<html>

<head>

    <meta charset="UTF-8">

    <title>My Flask App</title>

    <link
        rel="icon"
        href="{{ url_for('static', filename='favicon.ico') }}"
    >

</head>

<body>

    <h1>Hello Flask</h1>

</body>

</html>
```

That's all you need for a basic favicon.

---

# 3. What Does `rel="icon"` Mean?

This:

```
rel="icon"
```

tells the browser:

> This linked resource is the icon for this webpage.

And:

```
href="..."
```

specifies where the icon is located.

So:

```
<link
    rel="icon"
    href="{{ url_for('static', filename='favicon.ico') }}"
>
```

means:

```
Browser
   ↓
This is the website icon
   ↓
Get it from Flask's static directory
```

---

# 4. Why Use `url_for()`?

You could technically write:

```
<link rel="icon" href="/static/favicon.ico">
```

But Flask applications generally prefer:

```
<link
    rel="icon"
    href="{{ url_for('static', filename='favicon.ico') }}"
>
```

because Flask generates the correct URL for you.

This is the same pattern you've already learned:

```
{{ url_for('static', filename='css/style.css') }}
```

```
{{ url_for('static', filename='js/script.js') }}
```

```
{{ url_for('static', filename='images/logo.png') }}
```

```
{{ url_for('static', filename='favicon.ico') }}
```

# 5. Recommended Location With Template Inheritance

If your application uses:

```
templates/
├── base.html
├── home.html
├── about.html
└── contact.html
```

put the favicon in `base.html`.

```
<head>

    <title>
        {% block title %}
        My Flask App
        {% endblock %}
    </title>

    <link
        rel="icon"
        href="{{ url_for('static', filename='favicon.ico') }}"
    >

</head>
```

Then:

```
base.html
    │
    ├── favicon
    ├── CSS
    └── other common resources
         │
         ├── home.html
         ├── about.html
         └── contact.html
```

Every page that extends `base.html` gets the favicon automatically.

# 6. Different Favicon Formats

You may encounter:

```
.ico
.png
.svg
```

For example:

```
static/
├── favicon.ico
└── favicon.png
```

### ICO

```
<link
    rel="icon"
    href="{{ url_for('static', filename='favicon.ico') }}"
>
```

### PNG

```
<link
    rel="icon"
    type="image/png"
    href="{{ url_for('static', filename='favicon.png') }}"
>
```

### SVG

```
<link
    rel="icon"
    type="image/svg+xml"
    href="{{ url_for('static', filename='favicon.svg') }}"
>
```

For a basic Flask application, `.ico` or `.png` is perfectly fine.

# 7. Favicon Sizes

Favicons can be provided in different sizes.

Common sizes include:

```
16 × 16
32 × 32
48 × 48
```

PNG favicons can be explicitly declared:

```
<link
    rel="icon"
    type="image/png"
    sizes="32x32"
    href="{{ url_for('static', filename='favicon-32x32.png') }}"
>
```

You might have:

```
static/
├── favicon-16x16.png
├── favicon-32x32.png
└── favicon-48x48.png
```

Then:

```
<link
    rel="icon"
    type="image/png"
    sizes="16x16"
    href="{{ url_for('static', filename='favicon-16x16.png') }}"
>

<link
    rel="icon"
    type="image/png"
    sizes="32x32"
    href="{{ url_for('static', filename='favicon-32x32.png') }}"
>

<link
    rel="icon"
    type="image/png"
    sizes="48x48"
    href="{{ url_for('static', filename='favicon-48x48.png') }}"
>
```

For your notes, you don't need to memorize all of these variations right now.

The basic version is enough:

```
<link
    rel="icon"
    href="{{ url_for('static', filename='favicon.ico') }}"
>
```

# 8. Favicon vs Logo

These are **not the same thing**.

A website logo might be:

```
static/images/logo.png
```

and appear inside the page:

```
<img
    src="{{ url_for('static', filename='images/logo.png') }}"
    alt="Website Logo"
>
```

A favicon appears in the browser UI:

```
static/favicon.ico
```

and is referenced with:

```
<link
    rel="icon"
    href="{{ url_for('static', filename='favicon.ico') }}"
>
```

Think of it this way:

```
Website
│
├── Logo
│     ↓
│   Inside webpage
│
└── Favicon
      ↓
    Browser tab / bookmark
```

# 9. Favicon Not Appearing?

This is a surprisingly common issue.

If you've correctly added:

```
<link
    rel="icon"
    href="{{ url_for('static', filename='favicon.ico') }}"
>
```

but don't see the icon, check the following.

### 1. File location

Make sure:

```
static/favicon.ico
```

actually exists.

### 2. Generated URL

The browser should request something like:

```
/static/favicon.ico
```

### 3. Network tab

Open:

```
F12
↓
Network
```

Reload the page.

Find:

```
favicon.ico
```

You want a successful response such as:

```
200
```

If you get:

```
404
```

the path is wrong or the file doesn't exist.

---

# 10. Browser Cache

Favicons are often heavily cached by browsers.

This can cause a confusing situation:

```
You changed favicon
        ↓
Refresh
        ↓
Old favicon still appears
```

Try:

```
Ctrl + F5
```

or clear the browser cache.

You can also inspect the favicon request in Developer Tools.

So don't immediately assume Flask is broken. Sometimes the browser is simply clutching onto the old icon like a tiny digital hoarder. 🗃️

# 11. Favicon With `base.html`

A good real-world Flask structure is:

```
project/
│
├── app.py
│
├── templates/
│   ├── base.html
│   ├── home.html
│   └── about.html
│
└── static/
    ├── css/
    │   └── style.css
    │
    ├── js/
    │   └── script.js
    │
    ├── images/
    │   └── logo.png
    │
    ├── fonts/
    │   └── MyFont.woff2
    │
    └── favicon.ico
```

### `base.html`

```
<!DOCTYPE html>

<html>

<head>

    <meta charset="UTF-8">

    <title>
        {% block title %}
        My Flask App
        {% endblock %}
    </title>

    <link
        rel="icon"
        href="{{ url_for('static', filename='favicon.ico') }}"
    >

    <link
        rel="stylesheet"
        href="{{ url_for('static', filename='css/style.css') }}"
    >

</head>

<body>

    {% block content %}
    {% endblock %}

    <script
        src="{{ url_for('static', filename='js/script.js') }}"
    ></script>

</body>

</html>
```

Now every child template inherits:

```
Favicon
CSS
JavaScript
```
