Static files are files that Flask **serves directly to the browser** rather than generating dynamically through Python or Jinja2.

The most common static files are:

```
CSS
JavaScript
Images
Fonts
favicon
```

These are essential for turning a plain Flask application into a proper web application.

---

# 1. What Are Static Files?

A Flask application generally deals with two kinds of content:

### Dynamic content

Generated by Flask/Python:

```
@app.route("/")
def home():
    return render_template("home.html")
```

Examples:

- User information
- Database results
- Calculated values
- API responses
- Personalized pages

### Static content

Files that are served essentially as they are:

```
CSS
JavaScript
Images
Fonts
favicon
```

For example:

```
style.css
script.js
logo.png
favicon.ico
```

The browser downloads these files and uses them.

---

# 2. Dynamic vs Static

Think of it this way:

```
                    Flask
                      │
          ┌───────────┴───────────┐
          │                       │
       Dynamic                  Static
          │                       │
          ▼                       ▼
      Python/Jinja           CSS/JS/images
          │                       │
          ▼                       ▼
     Generate page          Serve file
```

For example:

```
/templates/home.html
```

is a template.

But:

```
/static/css/style.css
```

is a static file.

---

# 3. Flask's `static` Directory

Flask has a conventional directory named:

```
static/
```

A typical project looks like:

```
myproject/
│
├── app.py
│
├── templates/
│   └── home.html
│
└── static/
    ├── css/
    ├── js/
    ├── images/
    └── fonts/
```

Flask automatically knows about the `static` directory in a standard application.

---

# 4. Why Separate `templates` and `static`?

They serve different purposes.

```
templates/
    ↓
HTML templates processed by Jinja2

static/
    ↓
Files sent to the browser
```

For example:

```
templates/
└── home.html
```

might contain:

```
<h1>Hello {{ name }}</h1>
```

Jinja2 processes that.

But:

```
static/css/style.css
```

contains ordinary CSS:

```
body {
    font-family: Arial;
}
```

It doesn't need Jinja2 processing.

---

# 5. Your First CSS File

Project:

```
myproject/
│
├── app.py
│
├── templates/
│   └── home.html
│
└── static/
    └── css/
        └── style.css
```

### `style.css`

```
body {
    font-family: Arial;
}

h1 {
    color: blue;
}
```

Now we need to connect this CSS file to our HTML.

---

# 6. Linking CSS

In `home.html`:

```
<link rel="stylesheet"
      href="{{ url_for('static', filename='css/style.css') }}">
```

The important part is:

```
{{ url_for('static', filename='css/style.css') }}
```

Flask generates the correct URL for the static file.

---

# 7. Why Use `url_for()`?

You might be tempted to write:

```
<link rel="stylesheet" href="/static/css/style.css">
```

This may work.

But Flask recommends using:

```
{{ url_for('static', filename='css/style.css') }}
```

because Flask generates the URL for you.

So:

```
<link rel="stylesheet"
      href="{{ url_for('static', filename='css/style.css') }}">
```

is the preferred Flask approach.

---

# 8. Understanding `url_for('static', ...)`

Let's break this down:

```
{{ url_for('static', filename='css/style.css') }}
```

### `url_for()`

Flask's URL-generation function.

### `'static'`

Refers to Flask's static-file endpoint.

### `filename`

Specifies which file you want.

### `'css/style.css'`

The path **inside the `static` directory**.

So:

```
static/
└── css/
    └── style.css
```

becomes:

```
css/style.css
```

inside `filename`.

---

# 9. Complete Example

### `app.py`

```
from flask import Flask, render_template

app = Flask(__name__)


@app.route("/")
def home():
    return render_template("home.html")


if __name__ == "__main__":
    app.run(debug=True)
```

### `templates/home.html`

```
<!DOCTYPE html>

<html>

<head>

    <title>Home</title>

    <link rel="stylesheet"
          href="{{ url_for('static', filename='css/style.css') }}">

</head>

<body>

    <h1>Hello Flask</h1>

</body>

</html>
```

### `static/css/style.css`

```
body {
    font-family: Arial;
}

h1 {
    color: blue;
}
```

When you open the page, Flask serves the HTML and the browser separately requests the CSS.

---

# 10. What Happens Behind the Scenes?

When the browser requests:

```
/
```

Flask runs:

```
@app.route("/")
def home():
```

and returns:

```
home.html
```

The browser sees:

```
<link rel="stylesheet"
      href="/static/css/style.css">
```

Then the browser makes another HTTP request:

```
GET /static/css/style.css
```

Flask serves:

```
static/css/style.css
```

So the process is:

```
Browser
   │
   │ GET /
   ▼
Flask
   │
   └── home.html
          │
          ▼
       Browser
          │
          │ GET /static/css/style.css
          ▼
       Flask
          │
          └── style.css
```

This distinction is very important.

# 11. Static JavaScript

Create:

```
static/
└── js/
    └── script.js
```

### `script.js`

```
console.log("JavaScript loaded");
```

Then include it:

```
<script src="{{ url_for('static', filename='js/script.js') }}"></script>
```

Usually put your scripts near the end of `<body>`:

```
<body>

    <h1>Hello Flask</h1>

    <script src="{{ url_for('static', filename='js/script.js') }}"></script>

</body>
```

# 12. Static Images

Suppose:

```
static/
└── images/
    └── logo.png
```

Use:

```
<img src="{{ url_for('static', filename='images/logo.png') }}"
     alt="Logo">
```

Again:

```
static/images/logo.png
```

becomes:

```
filename='images/logo.png'
```

---

# 13. Static Fonts

Suppose:

```
static/
└── fonts/
    └── MyFont.woff2
```

You can reference it from CSS.

For example:

```
@font-face {
    font-family: "MyFont";
    src: url("../fonts/MyFont.woff2");
}

body {
    font-family: "MyFont";
}
```

The browser requests the font as another static resource.

---

# 14. Favicon

A favicon is the small icon displayed in the browser tab.

Project:

```
static/
└── favicon.ico
```

In your HTML:

```
<link rel="icon"
      href="{{ url_for('static', filename='favicon.ico') }}">
```

You can also use PNG:

```
static/
└── images/
    └── favicon.png
```

Then:

```
<link rel="icon"
      type="image/png"
      href="{{ url_for('static', filename='images/favicon.png') }}">
```

# 16. Static Files and Template Inheritance

This is where Module 4 and Module 5 connect.

Instead of putting your CSS link in every page, put it in `base.html`.

### `base.html`

```
<head>

    <title>
        {% block title %}
            My Website
        {% endblock %}
    </title>

    <link rel="stylesheet"
          href="{{ url_for('static', filename='css/style.css') }}">

</head>
```

Then:

```
home.html
about.html
login.html
```

can all extend:

```
base.html
```

and automatically receive the CSS.

---

# 17. Page-Specific CSS

Sometimes one page needs additional CSS.

You can create a block in `base.html`:

```
<head>

    <link rel="stylesheet"
          href="{{ url_for('static', filename='css/style.css') }}">

    {% block styles %}
    {% endblock %}

</head>
```

Then in a child template:

```
{% extends "base.html" %}

{% block styles %}

<link rel="stylesheet"
      href="{{ url_for('static', filename='css/dashboard.css') }}">

{% endblock %}
```

Now:

```
Every page
    ↓
style.css

Dashboard
    ↓
style.css
+
dashboard.css
```

This combines **template inheritance** with **static files**.

---

# 18. Page-Specific JavaScript

You can do the same thing with JavaScript.

In `base.html`:

```
<body>

    {% block content %}
    {% endblock %}


    <script src="{{ url_for('static', filename='js/main.js') }}"></script>

    {% block scripts %}
    {% endblock %}

</body>
```

Child:

```
{% block scripts %}

<script src="{{ url_for('static', filename='js/dashboard.js') }}"></script>

{% endblock %}
```

Very common pattern.

---

# 19. Static URL

By default, Flask serves static files under:

```
/static/
```

For example:

```
static/css/style.css
```

is normally available through:

```
/static/css/style.css
```

But in templates, prefer:

```
{{ url_for('static', filename='css/style.css') }}
```

instead of hardcoding the URL.

---

# 20. Custom Static Folder

Flask allows you to change the static directory.

For example:

```
app = Flask(
    __name__,
    static_folder="assets"
)
```

Now Flask uses:

```
assets/
```

instead of:

```
static/
```

So:

```
assets/
└── css/
    └── style.css
```

can be referenced using:

```
{{ url_for('static', filename='css/style.css') }}
```

Notice something interesting:

The endpoint can still be:

```
static
```

even though the physical folder is called `assets`.

That's because `static` here refers to Flask's endpoint, not necessarily the physical directory name.

---

# 21. Custom Static URL

You can also change the URL prefix:

```
app = Flask(
    __name__,
    static_folder="assets",
    static_url_path="/assets"
)
```

Now:

```
assets/css/style.css
```

could be served at:

```
/assets/css/style.css
```

This is an advanced configuration and isn't necessary for normal projects.

---

# 22. Static Files Are Not Templates

This distinction is important.

### Template

```
templates/home.html
```

can contain:

```
<h1>Hello {{ username }}</h1>
```

Jinja2 processes it.

### Static file

```
static/js/script.js
```

contains:

```
console.log("Hello");
```

Flask doesn't normally process that JavaScript file through Jinja2.

So don't assume you can write:

```
console.log("{{ username }}");
```

inside a static `.js` file and expect Jinja2 to replace it.

---

# 23. Passing Flask Data to JavaScript

This is an important concept you'll encounter later.

Suppose Flask has:

```
@app.route("/")
def home():

    username = "John"

    return render_template(
        "home.html",
        username=username
    )
```

Your external JavaScript file:

```
static/js/script.js
```

doesn't automatically know about `username`.

The browser receives the JavaScript separately.

One common approach is to place data into the HTML and let JavaScript read it.

For example:

```
<div id="user"
     data-username="{{ username }}">
</div>
```

Then JavaScript can read:

```
const element = document.getElementById("user");

const username = element.dataset.username;

console.log(username);
```

There are other approaches too, especially when working with APIs.

We'll revisit this when we study REST APIs.

---

# 24. Browser Caching

Static files are often cached by browsers.

For example:

```
style.css
```

might be downloaded once and then reused from the browser cache.

This improves performance.

But during development, you may sometimes change CSS and not immediately see the changes because the browser is using a cached version.

A hard refresh can help.

---

# 25. Why CSS Changes Sometimes Don't Appear

Suppose you change:

```
h1 {
    color: red;
}
```

but the browser still shows the old style.

Possible causes include:

```
Wrong file path
Wrong CSS file
Browser cache
CSS syntax error
Another CSS rule overriding it
```

First inspect the browser's developer tools and verify that the CSS file is actually being requested.

# 26. Static File 404 Error

If you see:

```
404 Not Found
```

for:

```
/static/css/style.css
```

check:

### Project structure

```
project/
├── app.py
└── static/
    └── css/
        └── style.css
```

### Template path

```
{{ url_for('static', filename='css/style.css') }}
```

Make sure the spelling and capitalization match.

For example:

```
style.css
```

is not necessarily the same as:

```
Style.css
```

on all deployment environments.

---

# 27. Common Mistake

Incorrect:

```
{{ url_for('static', 'css/style.css') }}
```

Better:

```
{{ url_for('static', filename='css/style.css') }}
```

Because `filename` is the argument used to specify the static file.

---

# 28. Another Common Mistake

If the file is:

```
static/css/style.css
```

don't write:

```
filename='static/css/style.css'
```

Instead:

```
filename='css/style.css'
```

Why?

Because Flask already knows:

```
static/
```

is the static directory.

So:

```
static/ + css/style.css
       ↓
static/css/style.css
```

# 29. Static File Request Flow

Let's put everything together.

You visit:

```
/
```

Flask returns:

```
home.html
```

The HTML contains:

```
<link rel="stylesheet"
      href="/static/css/style.css">
```

The browser then requests:

```
GET /static/css/style.css
```

Flask finds:

```
static/css/style.css
```

and sends it to the browser.

Then the browser applies the CSS.

The same process happens for:

```
JavaScript
Images
Fonts
favicon
```

# 30. Complete Example

### Project

```
myproject/
│
├── app.py
│
├── templates/
│   └── base.html
│
└── static/
    │
    ├── css/
    │   └── style.css
    │
    ├── js/
    │   └── script.js
    │
    ├── images/
    │   └── logo.png
    │
    └── favicon.ico
```

### `base.html`

```
<!DOCTYPE html>

<html>

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>
        {% block title %}
            My Website
        {% endblock %}
    </title>

    <link rel="icon"
          href="{{ url_for('static', filename='favicon.ico') }}">

    <link rel="stylesheet"
          href="{{ url_for('static', filename='css/style.css') }}">

</head>

<body>

    <img src="{{ url_for('static', filename='images/logo.png') }}"
         alt="Logo">

    {% block content %}
    {% endblock %}

    <script src="{{ url_for('static', filename='js/script.js') }}"></script>

</body>

</html>
```

Now one template is connected to:

```
favicon.ico
     ↓
style.css
     ↓
logo.png
     ↓
script.js
```

# 32. The Mental Model

Remember this structure:

```
                 Flask Application
                        │
             ┌──────────┴──────────┐
             │                     │
        templates/              static/
             │                     │
             ▼                     ▼
          Jinja2              Direct files
             │                     │
             │              ┌──────┼──────┐
             │              │      │      │
             │             CSS    JS   Images
             │
             ▼
        Dynamic HTML
             │
             └──────────┬──────────┘
                        ▼
                     Browser
```

The key difference:

> **Templates are processed by Jinja2. Static files are served to the browser as static resources.**
