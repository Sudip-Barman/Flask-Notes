# Defination

Flask is a **lightweight Python web framework** used to build web applications, REST APIs, dashboards, admin panels, and backend services.

It provides the tools required to create a web server, handle HTTP requests, and return responses without forcing a specific project structure.

>    **In simple words:** Flask lets you build websites and web applications using Python.

# Why was Flask created?


Before Flask, developers often had to write repetitive code to:

- Start a web server
- Handle URLs
- Process requests
- Send responses
- Manage sessions
- Handle cookies

Flask simplifies these tasks so you can focus on your application's logic.

### Real-Life Analogy

Imagine a restaurant.

```

Customer
    │
    │ Orders Food
    ▼
Waiter
    │
    ▼
Chef
    │
    │ Cooks Food
    ▼
Waiter
    │
    ▼
Customer receives food

```

A web application works almost the same way.

```

Browser
    │
    │ HTTP Request
    ▼
Flask Server
    │
    ▼
Python Code
    │
    ▼
Database
    │
    ▼
Flask Server
    │
    │ HTTP Response
    ▼
Browser
```
Flask acts like the **waiter**.

# Why Learn Flask?

Flask is popular because it is:

- Easy to learn
- Lightweight
- Flexible
- Fast to develop with
- Written in Python
- Great for beginners
- Powerful enough for production

Many startups use Flask because it allows rapid development.

## Advantages of Flask


### 1. Lightweight

Flask only includes the essentials. You install extra features only when needed.
### 2. Flexible

Unlike larger frameworks, Flask lets you organize your project however you like.
### 3. Python-Based

If you know Python, learning Flask is much easier than learning many other backend frameworks.
### 4. Large Community

Thousands of tutorials, extensions, and libraries are available.
### 5. Easy Integration

Flask works well with:

- MySQL
- PostgreSQL
- SQLite
- MongoDB
- Redis
- Docker
- Google Cloud
- AWS
- React
- Vue
- Angular


# Disadvantages of Flask

- Fewer built-in features compared to Django.
- You need to choose and configure many libraries yourself.
- Large applications require good project organization.

# Popular Websites Using Flask

- Pinterest

- Reddit
- Lyft

This doesn't necessarily mean their entire platform runs on Flask, but it shows Flask is trusted for production use.
