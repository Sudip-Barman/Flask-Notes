# Step 3: Write Your First Flask Program

```
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Hello, Flask!"

```

# Understanding Every Line

## Line 1

```
from flask import Flask
```

### Purpose

Imports the **Flask** class from the `flask` package.

Without this import, Python doesn't know what Flask is.

---

## Line 2

```
app = Flask(__name__)
```

### Purpose

Creates a Flask application object.

Think of it as creating your web application.

```
Flask Class
      │
      ▼
Creates
      │
      ▼
Flask Application
```

### Why `__name__`?

`__name__` is a special Python variable.

When you run `app.py` directly:

```
__name__

↓

"__main__"
```

Flask uses it to determine important information such as the location of your project files (like the `templates` and `static` folders).

> For now, just remember: **always write** `Flask(__name__)`.

---

## Line 3

```
@app.route("/")
```

This is called a **decorator**.

### What is a decorator?

A decorator attaches additional behavior to a function.

Here it tells Flask:

> "When someone visits `/`, execute the function below."

`/` is called the **root URL** or **home route**.

---

## Line 4

```
def home():
```

This is a normal Python function.

Flask calls it automatically when the matching route is requested.

---

## Line 5

```
return "Hello, Flask!"
```

Whatever this function returns becomes the HTTP response sent back to the browser.

Browser output:

```
Hello, Flask!
```

---

## Line 6

```
if __name__ == "__main__":
```

This is standard Python.

It checks whether the file is being run directly.

If yes, the server starts.

If the file is imported into another Python file, this block is skipped.

---

## Line 7

```
app.run()
```

Starts Flask's built-in **development server**.

The server listens for incoming HTTP requests.

# Adding Another Route

You can define multiple pages by creating more routes.

```
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Home Page"

@app.route("/about")
def about():
    return "About Page"

@app.route("/contact")
def contact():
    return "Contact Page"

if __name__ == "__main__":
    app.run()
```

Visit:

```
http://127.0.0.1:5000/
```

Output:

```
Home Page
```

Visit:

```
http://127.0.0.1:5000/about
```

Output:

```
About Page
```

Visit:

```
http://127.0.0.1:5000/contact
```

Output:

```
Contact Page
```

# Common Mistakes

### ❌ Forgetting `@app.route()`

```
def home():
    return "Hello"
```

The function exists, but Flask doesn't know which URL should call it.

---

### ❌ Forgetting `return`

```
@app.route("/")
def home():
    print("Hello")
```

`print()` writes to the terminal, not the browser. Flask expects the function to **return** a response.

---

### ❌ Two routes with the same URL

```
@app.route("/")
def home():
    ...

@app.route("/")
def index():
    ...
```

Each route should be unique.

---

### ❌ Running without activating the virtual environment

You may get:

```
ModuleNotFoundError: No module named 'flask'
```

Activate `.venv` first.

---

# Best Practices

- Give route functions meaningful names.
- Return responses instead of using `print()`.
- Keep route functions short. Move complex logic into separate functions or modules as your project grows.
- Use one route per unique URL.
