# What is pip?

## Definition

**pip** (Pip Installs Packages) is Python's package manager.

It downloads and installs Python libraries from the **Python Package Index (PyPI)**.

Example:

```
pip install flask
```

---

## Common pip Commands

### Install a package

```
pip install flask
```

---

### Upgrade a package

```
pip install --upgrade flask
```

---

### Uninstall a package

```
pip uninstall flask
```

---

### Show installed packages

```
pip list
```

---

### Show package information

```
pip show flask
```

Example output:

```
Name: Flask
Version: 3.x.x
Summary: A simple framework for building web applications
```

---

### Save installed packages

```
pip freeze > requirements.txt
```

This creates a file like:

```
Flask==3.x.x
Werkzeug==...
Jinja2==...
click==...
itsdangerous==...
blinker==...
```

---

### Install from requirements.txt

```
pip install -r requirements.txt
```

This is how projects share their dependencies.

# Flask Dependencies

When you install Flask, pip also installs several packages that Flask depends on.

|Package|Purpose|
|---|---|
|Werkzeug|Handles HTTP requests, routing, and the development server|
|Jinja2|Template engine for generating HTML|
|Click|Command-line interface support|
|ItsDangerous|Securely signs data such as session cookies|
|Blinker|Supports signals (used by Flask when available)|

You usually don't install these separately because `pip install flask` handles them automatically.

# Common Installation Errors

## Error 1

```
'pip' is not recognized as an internal or external command
```

### Cause

- pip is not installed.
- Python's Scripts directory is not in your system PATH.

### Solution

Try:

```
python -m pip install flask
```

---

## Error 2

```
ModuleNotFoundError: No module named 'flask'
```

### Cause

Flask is not installed in the Python interpreter you're using.

### Solution

Install it in the active environment:

```
python -m pip install flask
```

---

## Error 3

```
Permission denied
```

### Solution

On Windows, run the terminal as Administrator if necessary. More commonly, create and use a virtual environment, which avoids installing packages system-wide.
