
## Definition

**HTTP (HyperText Transfer Protocol)** is the communication protocol that allows a **client** (such as a web browser or mobile app) to communicate with a **server**.

It defines **how requests are sent** and **how responses are returned**.

> Think of HTTP as the language spoken between your browser and a Flask application.
# Why Do We Need HTTP?

Imagine a browser and a server trying to communicate without any rules.

```
Browser:
"Give me the home page."

Server:
"What format?"

Browser:
"I don't know."

Server:
"I don't understand."
```

Without a common protocol, communication would fail.

HTTP provides a standard set of rules so every browser and every web server understand each other.

---

# Real-Life Example

Suppose you open:

```
http://127.0.0.1:5000/about
```

The browser sends an HTTP request.

```
GET /about HTTP/1.1
```

Flask processes the request.

Flask sends a response.

```
HTTP/1.1 200 OK

About Page
```

The browser displays:

```
About Page
```

# HTTP URL Structure

Example:

```
https://www.example.com/products?id=10
```

Breakdown:

| Part              | Description     |
| ----------------- | --------------- |
| `https`           | Protocol        |
| `www.example.com` | Domain Name     |
| `/products`       | Route or Path   |
| `?id=10`          | Query Parameter |

# HTTP Methods

HTTP defines different methods (also called verbs) to tell the server what action the client wants to perform.

|Method|Purpose|
|---|---|
|GET|Retrieve data|
|POST|Send new data|
|PUT|Replace existing data|
|PATCH|Update part of existing data|
|DELETE|Remove data|

---

## GET

Used to retrieve information.

Example:

```
GET /students
```

Meaning:

```
Give me all students.
```

---

## POST

Used to create new data.

Example:

```
POST /students
```

Data:

```
{
    "name": "Sudip",
    "age": 21
}
```

Meaning:

```
Create a new student.
```

---

## PUT

Replaces an existing resource.

```
PUT /students/5
```

Meaning:

```
Replace all information for student 5.
```

---

## PATCH

Updates only specific fields.

```
PATCH /students/5
```

Data:

```
{
    "age": 22
}
```

Meaning:

```
Update only the age of student 5.
```

---

## DELETE

Removes data.

```
DELETE /students/5
```

Meaning:

```
Delete student 5.
```

---

# HTTP Status Codes

After processing a request, the server returns a **status code** to indicate the result.

## 2xx: Success

|Code|Meaning|
|---|---|
|200|OK|
|201|Created|
|204|No Content|

---

## 3xx: Redirection

|Code|Meaning|
|---|---|
|301|Moved Permanently|
|302|Found (Temporary Redirect)|

---

## 4xx: Client Errors

|Code|Meaning|
|---|---|
|400|Bad Request|
|401|Unauthorized|
|403|Forbidden|
|404|Not Found|
|405|Method Not Allowed|

---

## 5xx: Server Errors

|Code|Meaning|
|---|---|
|500|Internal Server Error|
|502|Bad Gateway|
|503|Service Unavailable|

# HTTPS

HTTPS stands for **HyperText Transfer Protocol Secure**.

It is HTTP protected with **TLS (Transport Layer Security)** encryption.

|HTTP|HTTPS|
|---|---|
|Data is not encrypted|Data is encrypted|
|Less secure|More secure|
|Uses port 80|Uses port 443|

Today, almost every public website uses HTTPS.

# HTTP Headers

Headers carry additional information about the request or response.

Example request:

```
GET / HTTP/1.1
Host: localhost:5000
User-Agent: Chrome
Accept: text/html
```

Example response:

```
HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 1256
```

You'll work with headers frequently in Flask APIs.

---
