Query parameters are values passed in the URL after a `?`.

For example:

```
http://127.0.0.1:5000/search?q=flask
```

Everything after `?` is called a **query parameter**.

```
?q=flask
```

Here:

- `q` = Parameter name
- `flask` = Parameter value

---

## Why Do We Use Query Parameters?

They are commonly used for:

- Search
- Filtering
- Pagination
- Sorting
- Customizing results

Examples:

```
/search?q=python

/products?category=laptop

/users?page=2

/posts?sort=latest

/items?price=1000
```

## Syntax

In Flask:

```
request.args.get("parameter_name")
```

---

## First Example

```
from flask import Flask, request

app = Flask(__name__)

@app.route("/search")
def search():

    name = request.args.get("name")

    return f"Hello {name}"
```

Visit:

```
http://127.0.0.1:5000/search?name=Sudip
```

Output:

```
Hello Sudip
```

---

## How It Works

Browser sends:

```
GET /search?name=Sudip
```

Flask creates:

```
request.args
```

which contains:

```
{
    "name": "Sudip"
}
```

Then:

```
request.args.get("name")
```

returns:

```
"Sudip"
```

## Multiple Query Parameters

Example:

```
/search?name=Sudip&age=21
```

Notice the `&`.

```
name=Sudip
&
age=21
```

Code:

```
@app.route("/search")
def search():

    name = request.args.get("name")
    age = request.args.get("age")

    return f"{name} is {age} years old."
```

Output:

```
Sudip is 21 years old.
```

@app.route("/search")

## Example: Pagination

Suppose a website has 1000 products.

Instead of showing all of them:

```
/products?page=1

/products?page=2

/products?page=3
```

Code:

```
@app.route("/products")
def products():

    page = request.args.get("page")

    return f"Page {page}"
```

---

Visit:

```
/products?page=5
```

Output:

```
Page 5
```

---

## Default Values

What if the user visits:

```
/products
```

without:

```
?page=1
```

You can provide a default value:

```
page = request.args.get(
    "page",
    1
)
```

Now:

```
/products
```

Output:

```
1
```

---

## Type Conversion

Everything from `request.args` is a string.

Example:

```
/products?page=5
```

Flask reads:

```
"5"
```

not:

```
5
```

You can convert it:

```
page = int(
    request.args.get(
        "page",
        1
    )
)
```

Or use Flask's built-in type conversion:

```
page = request.args.get(
    "page",
    type=int
)
```

Example:

```
page = request.args.get(
    "page",
    default=1,
    type=int
)
```

This is the preferred way.

## Complete Example

```
from flask import Flask, request

app = Flask(__name__)

@app.route("/user")
def user():

    name = request.args.get(
        "name",
        default="Guest"
    )

    age = request.args.get(
        "age",
        type=int,
        default=0
    )

    return f"{name} ({age})"
```

Visit:

```
/user?name=Sudip&age=21
```

Output:

```
Sudip (21)
```

Visit:

```
/user
```

Output:

```
Guest (0)
```

## Common Mistakes

### ❌ Using `request.form`

Wrong:

```
request.form["name"]
```

For:

```
/search?name=Sudip
```

Correct:

```
request.args.get("name")
```

---

### ❌ Forgetting `?`

Wrong:

```
/searchname=Sudip
```

Correct:

```
/search?name=Sudip
```

---

### ❌ Forgetting `&`

Wrong:

```
/search?name=Sudipage=21
```

Correct:

```
/search?name=Sudip&age=21
```

---

## Best Practices

Use:

```
request.args.get()
```

instead of:

```
request.args["name"]
```

because `.get()` avoids errors if the parameter doesn't exist.
