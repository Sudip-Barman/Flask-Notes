Cookies are one of the most important concepts in web development because HTTP is **stateless**.

But before understanding cookies, let's understand the problem they solve.

---

## The Problem

Imagine this Flask application:

```
@app.route("/")
def home():
    return "Welcome!"
```

You visit:

```
http://127.0.0.1:5000/
```

Flask responds:

```
Welcome!
```

Then you refresh the page.

Does Flask remember you?

> No.

Every request is treated as a completely new visitor.

```
Request 1
↓
Flask: "Who are you?"

Request 2
↓
Flask: "Who are you?"

Request 3
↓
Flask: "Who are you?"
```

HTTP has no memory.

---

## Real Life Example

Imagine a coffee shop.

Without cookies:

```
Day 1:
Customer: I'm Sudip.
Shop: Nice to meet you.

Day 2:
Customer: I'm Sudip.
Shop: Never seen you before.

Day 3:
Customer: I'm Sudip.
Shop: Who are you?
```

That's how HTTP works.

---

## Solution: Cookies

Cookies are small pieces of data stored in the user's browser.

Example:

```
name = Sudip
theme = dark
language = english
```

Browser stores:

```
Cookie:
username=Sudip
```

On the next request:

```
GET /

Cookie:
username=Sudip
```

Now Flask can recognize the user.

---

## What is a Cookie?

> A cookie is a small piece of data stored in the browser and sent back to the server with every request.

---

## Visual Representation

```
User Visits Website

        ↓

Flask Sends Cookie

        ↓

Browser Stores Cookie

        ↓

Future Requests

        ↓

Browser Sends Cookie Back

        ↓

Flask Reads Cookie
```

---

## Creating Cookies

Flask provides:

```
set_cookie()
```

Example:

```
from flask import Flask, make_response

app = Flask(__name__)

@app.route("/")
def home():

    response = make_response(
        "Cookie Created!"
    )

    response.set_cookie(
        "username",
        "Sudip"
    )

    return response

app.run(debug=True)
```

---

## What Happens?

Flask sends:

```
Set-Cookie:
username=Sudip
```

Browser stores:

```
username=Sudip
```

---

## Reading Cookies

Flask provides:

```
request.cookies
```

Example:

```
from flask import request

@app.route("/profile")
def profile():

    username = request.cookies.get(
        "username"
    )

    return f"Hello {username}"
```

Output:

```
Hello Sudip
```

---

## Complete Example

```
from flask import (
    Flask,
    request,
    make_response
)

app = Flask(__name__)

@app.route("/")
def home():

    response = make_response(
        "Cookie Saved!"
    )

    response.set_cookie(
        "username",
        "Sudip"
    )

    return response


@app.route("/profile")
def profile():

    username = request.cookies.get(
        "username")

    return f"Welcome {username}"


app.run(debug=True)
```

### Step 1

Visit:

```
/
```

Browser stores:

```
username=Sudip
```

### Step 2

Visit:

```
/profile
```

Output:

```
Welcome Sudip
```

## Deleting Cookies

Set its expiration time to zero.

```
response.delete_cookie(
    "username"
)
```

Example:

```
@app.route("/logout")
def logout():

    response = make_response(
        "Logged Out"
    )

    response.delete_cookie(
        "username"
    )

    return response
```

---

## Expiration Time

Cookies can expire.

Example:

```
response.set_cookie(
    "username",
    "Sudip",
    max_age=3600
)
```

```
3600 seconds

=

1 hour
```

After one hour:

```
Cookie Deleted
```

---

## Permanent Cookies

```
response.set_cookie(
    "theme",
    "dark",
    max_age=86400
)
```

```
86400 seconds

=

1 day
```

---

## Important

Cookies are stored on the user's machine.

```
User's Browser

├── username
├── theme
├── language
└── cart_id
```

This means users can potentially inspect or modify them.

Therefore:

### Never Store

- Passwords
- Credit Card Numbers
- Secret Keys

Wrong:

```
response.set_cookie(
    "password",
    "123456"
)
```

---

## Cookies vs Sessions

|Cookies|Sessions|
|---|---|
|Stored in browser|Stored on server|
|User can view|User cannot view|
|Small data|Larger data|
|Less secure|More secure|

You'll learn sessions next.

## Common Mistakes

### Forgetting `make_response()`

Wrong:

```
return "Hello"
```

Correct:

```
response = make_response(
    "Hello"
)
```

because:

```
response.set_cookie(...)
```

requires a response object.

---

### Accessing Missing Cookies

Wrong:

```
request.cookies["username"]
```

Better:

```
request.cookies.get(
    "username"
)
```

## Interview Question

> What are cookies?

**Answer:**

> Cookies are small pieces of data stored in the client's browser and sent back to the server with each request. They are used to remember user-specific information such as preferences, themes, and login states.
