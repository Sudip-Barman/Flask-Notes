Headers are one of those Flask topics that seem invisible because you never type them manually in a browser, yet they are present in **every HTTP request**.

Think of a request as a package being delivered.

```
Package
│
├── Item Inside          → Body (Form, JSON, File)
├── Sender Information   → Headers
└── Delivery Address     → URL
```

For example, when your browser visits:

```
http://127.0.0.1:5000/
```

it secretly sends something like:

```
GET / HTTP/1.1

Host: 127.0.0.1:5000
User-Agent: Chrome
Accept: text/html
Accept-Language: en-US
```

You only typed:

```
http://127.0.0.1:5000/
```

But the browser added all those extra details automatically.

---

## What Are Headers?

Headers are metadata about the request.

Examples:

- Which browser is being used?
- Which language is preferred?
- What kind of data is being sent?
- Is the user authenticated?
- What API key is being used?

---

## Real-Life Analogy

Imagine ordering food online.

```
Order:

1 Burger
```

Additional information:

```
Name: Sudip
Phone: XXXXX
Address: Kolkata
Special Note: No onions
```

The burger is the main data.

The extra information is like HTTP headers.

---

## Accessing Headers

Flask provides:

```
request.headers
```

Example:

```
from flask import Flask, request

app = Flask(__name__)

@app.route("/")
def home():

    return str(request.headers)

app.run(debug=True)
```

Output:

```
Host: 127.0.0.1:5000
Connection: keep-alive
User-Agent: Mozilla/5.0 ...
Accept: text/html
Accept-Language: en-US
```

---

## Common Headers

|Header|Purpose|
|---|---|
|`Host`|Server address|
|`User-Agent`|Browser/App information|
|`Content-Type`|Type of incoming data|
|`Authorization`|Authentication token|
|`Accept`|Expected response type|
|`Accept-Language`|Preferred language|

---

## `User-Agent`

This tells Flask who is making the request.

Example:

```
@app.route("/")
def home():

    return request.headers.get(
        "User-Agent"
    )
```

Output:

```
Mozilla/5.0
```

or:

```
PostmanRuntime/7.43
```

or:

```
python-requests/2.32
```

This tells you whether the client is:

- Chrome
- Firefox
- Postman
- Python Script
- Android App

@app.route("/")

    return request.headers.get("Host")

Output:

```

```

## `Content-Type`

One of the most important headers.

Suppose the client sends JSON:

```
{
    "name": "Sudip"
}
```

The request also contains:

```
Content-Type: application/json
```

Flask uses this to understand:

> "This request contains JSON."

For forms:

```
Content-Type:
application/x-www-form-urlencoded
```

For file uploads:

```
Content-Type:
multipart/form-data
```

---

## Authorization Header

Modern APIs use:

```
Authorization:
Bearer abc123xyz
```

Example:

```
@app.route("/")
def home():

    token = request.headers.get(
        "Authorization"
    )

    return token
```

Output:

```
Bearer abc123xyz
```

You'll use this heavily in:

- JWT Authentication
- REST APIs
- User Login Systems

---

## Complete Example

```
from flask import Flask, request

app = Flask(__name__)

@app.route("/")
def home():

    user_agent = request.headers.get(
        "User-Agent"
    )

    host = request.headers.get(
        "Host"
    )

    return f"""
    Browser:
    {user_agent}

    Host:
    {host}
    """

app.run(debug=True)
```

## Why Are Headers Useful?

Imagine you want to allow only Android users:

```
if "Android" in request.headers.get(
    "User-Agent"
):
    return "Welcome Android User"
```

Or verify API tokens:

```
token = request.headers.get(
    "Authorization"
)

if token != "secret":

    return "Access Denied"
```

## Request Structure

Every HTTP request looks like this:

```
URL
↓
Headers
↓
Body
```

Example:

```
POST /chat

Headers:
Content-Type: application/json

Body:
{
    "message": "Explain Flask"
}
```

Flask receives:

```
request.headers
request.get_json()
```

Notice:

- Headers = Information about the request.
- Body = Actual data.

## Summary

|Flask Property|Purpose|
|---|---|
|`request.args`|URL data|
|`request.form`|Form data|
|`request.get_json()`|JSON data|
|`request.files`|Uploaded files|

Remember:

```
request.headers

=

Information about the request,
not the actual data.
```

## Interview Question

> What are HTTP headers?

**Answer:**

> HTTP headers are key-value pairs that provide metadata about an HTTP request or response, such as browser information, content type, authentication tokens, and accepted formats.
