## What is a Session?

A session is a way to store user-specific data securely between requests.

> Simple Definition:
> 
> A session is server-side storage that allows Flask to remember information about a user across multiple requests.

---

## Real-Life Analogy

Imagine a hotel.

### Step 1

You check in.

```
Name: Sudip
```

The hotel gives you:

```
Room Card: 101
```

The hotel stores:

```
Room 101
---------
Name: Sudip
Check-in: 10:00 AM
Room Type: Deluxe
```

You only carry:

```
101
```

---

Sessions work similarly:

```
Browser

Session ID: abc123

-------------------

Server

abc123
---------
username: Sudip
role: admin
```

The browser stores only an identifier, while the server stores the actual data.

---

## Cookies vs Sessions

| Cookies             | Sessions             |
| ------------------- | -------------------- |
| Browser stores data | Server stores data   |
| Less secure         | More secure          |
| User can see data   | User cannot see data |
| Small preferences   | Login information    |

## Using Sessions in Flask

Import:

```
from flask import session
```

---

## Flask Requires a Secret Key

Before using sessions:

```
app = Flask(__name__)

app.secret_key = "my_secret_key"
```

or:

```
app.config["SECRET_KEY"] = "my_secret_key"
```

Flask uses this key to sign session data securely.

---

## Storing Data in a Session

Example:

```
from flask import Flask, session

app = Flask(__name__)
app.secret_key = "secret"

@app.route("/")
def home():

    session["username"] = "Sudip"

    return "Session Created!"
```

Flask stores:

```
username = Sudip
```

---

## Reading Session Data

```
@app.route("/profile")
def profile():

    username = session.get(
        "username"
    )

    return f"Welcome {username}"
```

Output:

```
Welcome Sudip
```

---

## Complete Example

```
from flask import Flask, session

app = Flask(__name__)
app.secret_key = "secret"

@app.route("/")
def home():

    session["username"] = "Sudip"

    return "Logged In"


@app.route("/dashboard")
def dashboard():

    username = session.get(
        "username"
    )

    return f"Hello {username}"

app.run(debug=True)
```

---

### Step 1

Visit:

```
/
```

Flask:

```
session["username"] = "Sudip"
```

---

### Step 2

Visit:

```
/ dashboard
```

Output:

```
Hello Sudip
```

Flask remembered the user!

## Session Lifecycle

```
User Logs In

↓

Flask Creates Session

↓

Session ID Stored in Browser

↓

Actual Data Stored by Flask

↓

Future Requests

↓

Flask Finds Session

↓

User Recognized
```

## Login Example

```
@app.route("/login")
def login():

    session["user"] = "admin"

    return "Logged In"
```

---

```
@app.route("/admin")
def admin():

    if session.get("user"):

        return "Admin Panel"

    return "Access Denied"
```

---

Flow:

```
GET /login
↓
session["user"]="admin"

↓

GET /admin

↓

Admin Panel
```

---

## Removing Session Data

### Remove One Value

```
session.pop(
    "username",
    None
)
```

---

### Clear Everything

```
session.clear()
```

Example:

```
@app.route("/logout")
def logout():

    session.clear()

    return "Logged Out"
```

---

## Checking Sessions

```
if "username" in session:

    return "Logged In"
```

Example:

```
@app.route("/dashboard")
def dashboard():

    if "username" not in session:

        return "Please Login"

    return "Dashboard"
```

## Important Notes

Never store huge data in sessions.

Good:

```
session["user_id"] = 1
```

Bad:

```
session["entire_database"] = ...
```

Sessions should contain small pieces of information.

---

## Common Mistakes

### Forgetting Secret Key

Wrong:

```
app = Flask(__name__)
```

Result:

```
RuntimeError:
The session is unavailable because no secret key was set.
```

Correct:

```
app.secret_key = "secret"
```

---

### Accessing Missing Session Data

Wrong:

```
session["username"]
```

Better:

```
session.get(
    "username"
)
```

---

### Forgetting to Clear Session

Users should be logged out properly:

```
session.clear()
```
