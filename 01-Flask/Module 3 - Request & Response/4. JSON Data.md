## What is JSON?

JSON stands for:

```
JavaScript Object Notation
```

It is simply a way to represent data.

Example:

```
{
    "name": "Sudip",
    "age": 21,
    "city": "Kolkata"
}
```

Think of it as a Python dictionary.

```
{
    "name": "Sudip",
    "age": 21,
    "city": "Kolkata"
}
```

JSON and Python dictionaries look almost identical.

---

## Why Do We Need JSON?

Imagine your Android app sends:

```
Username: Sudip
Password: 123456
```

Can it send an HTML form?

```
<form>
    ...
</form>
```

No!

Mobile apps, React, and APIs usually send JSON.

Example:

```
{
    "username": "Sudip",
    "password": "123456"
}
```

Flask receives it using:

```
request.get_json()
```

---

## Real-Life Analogy

Imagine the user sends a sealed envelope:

```
{
    "name": "Sudip",
    "email": "abc@gmail.com"
}
```

Flask opens the envelope:

```
data = request.get_json()
```

Now:

```
data["name"]
```

returns:

```
Sudip
```

---

## First Example

```
from flask import Flask, request

app = Flask(__name__)

@app.route("/user", methods=["POST"])
def user():

    data = request.get_json()

    return data["name"]

if __name__ == "__main__":
    app.run(debug=True)
```

---

### Client Sends

```
{
    "name": "Sudip"
}
```

---

### Flask Receives

```

    "name": "Sudip"

```

### Output

```
Sudip
```

## Multiple Values

Client sends:

```
{
    "name": "Sudip",
    "age": 21,
    "city": "Kolkata"
}
```

Flask:

```
@app.route("/user", methods=["POST"])
def user():

    data = request.get_json()

    name = data["name"]
    age = data["age"]
    city = data["city"]

    return f"{name} {age} {city}"
```

Output:

```
Sudip 21 Kolkata
```

---

## Using `.get()`

Instead of:

```
name = data["name"]
```

Prefer:

```
name = data.get("name")
```

because:

```
data["name"]
```

throws an error if the key doesn't exist.

---

Example:

```
name = data.get("name", "Guest")
```

If `"name"` is missing:

```
Guest
```

is returned.

## JSON vs Form Data

|Feature|Form Data|JSON|
|---|---|---|
|Source|HTML Forms|APIs, React, Mobile Apps|
|Flask|`request.form`|`request.get_json()`|
|Format|`name=Sudip`|`{"name":"Sudip"}`|

## Sending JSON Using Python

```
import requests

response = requests.post(
    "http://127.0.0.1:5000/user",
    json={
        "name": "Sudip"
    }
)

print(response.text)
```

Output:

```
Sudip
```

## Real API Example

Suppose your AuLi app sends:

```
{
    "message": "Explain Flask",
    "mode": "study",
    "conversation_id": 5
}
```

Flask:

```
@app.route("/chat", methods=["POST"])
def chat():

    data = request.get_json()

    message = data.get("message")
    mode = data.get("mode")
    conversation_id = data.get(
        "conversation_id"
    )

    return message
```

Output:

```
Explain Flask
```

This is exactly how many APIs work.

## Common Mistakes

### ❌ Forgetting POST

Wrong:

```
@app.route("/user")
```

Correct:

```
@app.route(
    "/user",
    methods=["POST"]
)
```

---

### ❌ Using `request.form`

Wrong:

```
request.form.get("name")
```

for:

```
{
    "name": "Sudip"
}
```

Correct:

```
request.get_json()
```

---

### ❌ Forgetting JSON Body

If the client sends:

```
POST /user
```

with no JSON:

```
data = request.get_json()
```

returns:

```
None
```

---

## Safe Approach

```
data = request.get_json()

if data is None:
    return "No JSON received"
```

## Complete Example

```
from flask import Flask, request

app = Flask(__name__)

@app.route("/register", methods=["POST"])
def register():

    data = request.get_json()

    name = data.get("name")
    email = data.get("email")

    return f"""
    Name: {name}

    Email: {email}
    """

if __name__ == "__main__":
    app.run(debug=True)
```

Request:

```
{
    "name": "Sudip",
    "email": "abc@gmail.com"
}
```

Output:

```
Name: Sudip

Email: abc@gmail.com
```
