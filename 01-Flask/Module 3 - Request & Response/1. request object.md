The `request` object is one of the most important objects in Flask. It contains all the information sent by the client (browser, mobile app, API client, etc.) to your Flask application.

> **Simple Definition:**
> 
> The `request` object represents the current HTTP request and gives you access to everything the client sends.

---

## Why Do We Need the `request` Object?

Suppose a user:

- Logs in
- Registers
- Uploads a file
- Sends JSON data
- Searches for a product

How does Flask know what the user sent?

Answer:

```
from flask import request
```

The `request` object provides all this information.

## First Example

```
from flask import Flask, request

app = Flask(__name__)

@app.route("/")
def home():
    return request.method

if __name__ == "__main__":
    app.run(debug=True)
```

Visit:

```
http://127.0.0.1:5000/
```

Output:

```
GET
```

Because the browser used the GET method.

|Attribute|Description|
|---|---|
|`request.method`|HTTP method|
|`request.args`|Query parameters|
|`request.form`|Form data|
|`request.files`|Uploaded files|
|`request.headers`|Request headers|
|`request.cookies`|Cookies|
|`request.get_json()`|JSON data|

## `request.method`

Returns the HTTP method used.

```
@app.route("/login", methods=["GET", "POST"])
def login():
    return request.method
```

### GET Request

```
GET /login
```

Output:

```
GET
```

---

### POST Request

```
POST /login
```

Output:

```
POST
```

---

## `request.url`

Returns the complete URL.

```
@app.route("/")
def home():
    return request.url
```

Output:

```
http://127.0.0.1:5000/
```

---

## `request.path`

Returns only the path.

```
@app.route("/about")
def about():
    return request.path
```

Output:

```
/about
```

---

## `request.host`

Returns:

```
127.0.0.1:5000
```

Example:

```
@app.route("/")
def home():
    return request.host
```

---

## `request.headers`

Returns all request headers.

Example:

```
@app.route("/")
def home():

    return str(request.headers)
```

Output:

```
Host: 127.0.0.1:5000
User-Agent: Mozilla/5.0
Accept: text/html
...
```

Headers provide metadata about the request.

---

## `request.cookies`

Returns cookies sent by the browser.

```
@app.route("/")
def home():
    return str(request.cookies)
```

Output:

```
ImmutableMultiDict([])
```

If no cookies exist.

---

## `request.args`

Used for query parameters.

Example URL:

```
/search?name=Sudip
```

Code:

```
@app.route("/search")
def search():

    name = request.args.get("name")

    return f"Hello {name}"
```

Output:

```
Hello Sudip
```

---

## `request.form`

Used for HTML forms.

Example:

```
@app.route("/login", methods=["POST"])
def login():

    username = request.form["username"]

    return username
```

If the form sends:

```
username=Sudip
```

Output:

```
Sudip
```

---

## `request.files`

Used for uploaded files.

```
@app.route("/upload", methods=["POST"])
def upload():

    file = request.files["image"]

    return file.filename
```

If the user uploads:

```
profile.jpg
```

Output:

```
profile.jpg
```

---

## `request.get_json()`

Used for JSON data.

Example:

```
@app.route("/api", methods=["POST"])
def api():

    data = request.get_json()

    return data["name"]
```

Request:

```
{
    "name": "Sudip"
}
```

Output:

```
Sudip
```

## Complete Example

```
from flask import Flask, request

app = Flask(__name__)

@app.route("/", methods=["GET", "POST"])
def home():

    return f"""
    Method: {request.method}

    URL: {request.url}

    Path: {request.path}

    Host: {request.host}
    """

if __name__ == "__main__":
    app.run(debug=True)
```

Output:

```
Method: GET

URL: http://127.0.0.1:5000/

Path: /

Host: 127.0.0.1:5000
```

## `request` is Context-Specific

This is important:

```
print(request)
```

only works inside a request.

Wrong:

```
from flask import request

print(request)
```

Result:

```
RuntimeError:
Working outside of request context.
```

The `request` object only exists while handling an HTTP request.

---

## Common Mistakes

### ❌ Forgetting to Import

```
request.method
```

Without:

```
from flask import request
```

Result:

```
NameError
```

---

### ❌ Accessing Form Data in GET Requests

```
request.form["username"]
```

If no form was submitted:

```
BadRequestKeyError
```

Use:

```
request.form.get("username")
```

---

### ❌ Using `request` Outside a Route

Wrong:

```
print(request.method)
```

Outside:

```
@app.route()
```

Result:

```
RuntimeError
```

---

## Best Practices

- Use `.get()` when reading optional values.

```
request.args.get("name")
```

instead of:

```
request.args["name"]
```

---

- Keep request processing inside route functions.
- Validate all incoming data.
- Never trust user input directly.
