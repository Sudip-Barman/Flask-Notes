## What is Form Data?

Whenever a user fills an HTML form and clicks **Submit**, the browser sends the form's data to the Flask server.

Example:

```
Name: Sudip
Email: sudip@example.com

[Submit]
```

When the user clicks Submit, the browser sends:

```
name=Sudip
email=sudip@example.com
```

Flask receives this data using:

```
request.form
```

---

## The Golden Rule

Remember these two lines:

```
request.args  -> Data from the URL

request.form  -> Data from HTML Forms
```

---

## First HTML Form

Create:

### `templates/index.html`

```
<!DOCTYPE html>
<html>
<head>
    <title>Login</title>
</head>
<body>

    <form method="POST">

        <input
            type="text"
            name="username"
            placeholder="Enter Username"
        >

        <button type="submit">
            Submit
        </button>

    </form>

</body>
</html>
```

Notice:

```
name="username"
```

This is VERY important because Flask uses the `name` attribute to identify the data.

---

## Flask Code

```
from flask import Flask, render_template, request

app = Flask(__name__)

@app.route("/", methods=["GET", "POST"])
def home():

    if request.method == "POST":

        username = request.form.get("username")

        return f"Hello {username}"

    return render_template("index.html")

if __name__ == "__main__":
    app.run(debug=True)
```

## How It Works

### Step 1

Browser displays:

```
+------------------+
| Enter Username   |
+------------------+

[Submit]
```

---

### Step 2

User enters:

```
Sudip
```

---

### Step 3

User clicks:

```
Submit
```

---

### Step 4

Browser sends:

```
POST /

username=Sudip
```

---

### Step 5

Flask creates:

```
request.form
```

which contains:

```
{
    "username": "Sudip"
}
```

---

### Step 6

You write:

```
request.form.get("username")
```

Result:

```
"Sudip"
```

## Multiple Fields

HTML:

```
<form method="POST">

    <input name="name">

    <input name="age">

    <button>Submit</button>

</form>
```

User enters:

```
Name: Sudip
Age: 21
```

Browser sends:

```
name=Sudip
age=21
```

Flask:

```
name = request.form.get("name")
age = request.form.get("age")

return f"{name} is {age}"
```

Output:

```
Sudip is 21
```

## Login Form Example

HTML:

```
<form method="POST">

    <input name="username">

    <input
        type="password"
        name="password"
    >

    <button>
        Login
    </button>

</form>
```

User enters:

```
Username: Sudip
Password: 123456
```

Flask:

```
@app.route("/", methods=["POST"])
def login():

    username = request.form.get(
        "username"
    )

    password = request.form.get(
        "password"
    )

    return f"{username} {password}"
```

---

## Why `methods=["GET", "POST"]`?

Remember:

```
@app.route("/", methods=["GET", "POST"])
```

Because:

### GET

```
User opens page.
```

### POST

```
User submits form.
```

Flow:

```
GET

↓

Display Form

↓

User Fills Form

↓

POST

↓

Process Data
```

Without:

```
methods=["POST"]
```

Flask returns:

```
405 Method Not Allowed
```

---

## GET vs POST Forms

### GET Form

```
<form method="GET">
```

Suppose:

```
name=Sudip
```

URL becomes:

```
/search?name=Sudip
```

Use:

```
request.args.get("name")
```

---

### POST Form

```
<form method="POST">
```

URL remains:

```
/
```

Data is sent separately.

Use:

```
request.form.get("name")
```

---

## Comparison

|Feature|GET|POST|
|---|---|---|
|Visible in URL|Yes|No|
|Flask|`request.args`|`request.form`|
|Use Case|Search|Login/Register|

## Registration Form Example

HTML:

```
<form method="POST">

    <input name="name">

    <input name="email">

    <input name="password">

    <button>
        Register
    </button>

</form>
```

Flask:

```
@app.route(
    "/register",
    methods=["GET", "POST"]
)
def register():

    if request.method == "POST":

        name = request.form.get("name")
        email = request.form.get("email")
        password = request.form.get(
            "password"
        )

        return f"""
        {name}
        {email}
        {password}
        """

    return render_template(
        "register.html"
    )
```

This is how almost every registration system works.

## Common Mistakes

### ❌ Forgetting `name`

Wrong:

```
<input type="text">
```

Flask cannot access it.

Correct:

```
<input
    type="text"
    name="username"
>
```

---

### ❌ Using `request.args`

Wrong:

```
request.args.get(
    "username"
)
```

For a POST form.

Correct:

```
request.form.get(
    "username"
)
```

---

### ❌ Forgetting POST Method

Wrong:

```
@app.route("/")
def home():
```

Correct:

```
@app.route(
    "/",
    methods=["GET", "POST"]
)
```

---

## Best Practice

Prefer:

```
request.form.get(
    "username"
)
```

instead of:

```
request.form[
    "username"
]
```

because `.get()` avoids errors if the field doesn't exist.
