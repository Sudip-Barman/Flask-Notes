# 4.1 What is a Template?

A template is an HTML file containing **placeholders and instructions** that Flask/Jinja2 can process.

For example:

```
<h1>Hello, {{ name }}</h1>
```

Here:
```
{{ name }}
```

is a Jinja2 expression.

If Flask gives the template:

```
name = "John"
```

the final HTML becomes:

```
<h1>Hello, John</h1>
```

So:
```
Python Data
     ↓
Jinja2 Template
     ↓
HTML
     ↓
Browser
```

---

# What is Jinja2?

**Jinja2** is the template engine commonly used with Flask.

Flask itself handles things such as:

```
HTTP
Routing
Requests
Responses
Cookies
Sessions
```

Jinja2 handles:

```
HTML Templates
Variables
Loops
Conditions
Template Inheritance
```

Think of the relationship as:

```
Flask
 │
 ├── HTTP
 ├── Routing
 ├── Request
 ├── Response
 │
 └── Jinja2
      │
      └── HTML Templates
```

# Why Not Write HTML Directly in Python?

You technically can:

```
@app.route("/")
def home():
    return """
    <html>
        <body>
            <h1>Hello</h1>
        </body>
    </html>
    """
```

But imagine a real page with 500 lines of HTML.

Your Python file becomes a monster:

```
app.py
│
├── Python
├── HTML
├── CSS
├── JavaScript
└── more HTML...
```

Very difficult to maintain.

Instead, Flask separates Python and HTML:

```
project/
│
├── app.py
│
└── templates/
    └── home.html
```

Python handles the logic.

HTML handles the presentation.

Much cleaner.

---

# The `templates` Folder

Flask automatically looks for templates inside a folder named:

templates

Example:

```
myproject/
│
├── app.py
│
└── templates/
    │
    ├── home.html
    ├── about.html
    └── login.html
```

This folder name is important because Flask's default template loader looks there.

---

# `render_template()`

To render an HTML template, Flask provides:

**render_template()**

Import it:
```
from flask import Flask, render_template
```

Then:
```
@app.route("/")

def home():

    return render_template("home.html")
```

Flask finds:
```
templates/home.html
```

and sends the generated HTML to the browser.

```
myproject/
```

```
templates/home.html
```

# Dynamic Templates

Now the interesting part.

Suppose Python has:
```
name = "John"
```

We want the HTML to display:
```
Hello John
```
### Python
```
@app.route("/")
def home():
    name = "John"
    return render_template(
        "home.html",
        name=name
    )
```

### HTML
```
<h1>Hello, {{ name }}</h1>
```

Jinja2 replaces:
```
{{ name }}
```

with:
```
John
```

Final HTML sent to browser:
```
<h1>Hello, John</h1>
```

This is the central idea of Flask templates.

# Important Jinja2 Syntax

Jinja2 mainly uses three types of syntax.

### 1. Expression
```
{{ ... }}
```

Used to display something.

Example:
```
<h1>{{ name }}</h1>
```

---

### 2. Statement
```
{% ... %}
```

Used for logic.

For example:
```
{% if logged_in %}
    <p>Welcome!</p>
{% endif %}
```

We'll learn this properly in **Conditions**.

---

### 3. Comment
```
{# ... #}
```

Example:
```
{# This is a Jinja comment #}
```

It won't appear in the generated HTML.

---

# A Simple Mental Model

Remember these three:
```
{{ }}  → Show something

{% %}  → Do something

{# #}  → Comment something
```


For example:
```
<h1>{{ name }}</h1>

{% if age >= 18 %}
    <p>Adult</p>
{% endif %}

{# This won't be displayed #}
```

# Passing Multiple Values

You can send multiple variables from Flask.
```
@app.route("/")
def home():
    name = "John"
    age = 20
    city = "Delhi"
    return render_template(
        "home.html",
        name=name,
        age=age,
        city=city
    )
```

Template:
```
<h1>{{ name }}</h1>

<p>Age: {{ age }}</p>

<p>City: {{ city }}</p>
```

Output:
```
John

Age: 20

City: Delhi
```

---

# Passing a Dictionary

Instead of passing many individual variables:
```
@app.route("/")
def home():
    student = {
        "name": "John",
        "age": 20,
        "course": "BCA"
    }
    return render_template(
        "home.html",
        student=student
    )
```

Template:
```
<h1>{{ student.name }}</h1>

<p>{{ student.age }}</p>

<p>{{ student.course }}</p>
```

You can also use:
```
{{ student["name"] }}
```

Both can work with dictionary data.

Without templates:

```
   ↓
```

With templates:
```

Data
```

# Important Distinction

Don't confuse:
```
render_template()
```

with:
```
jsonify()
```

### `render_template()`

Used for **HTML pages**:
```
return render_template("home.html")
```

### `jsonify()`

Used for **JSON responses**:
```
return jsonify({
    "message": "Hello"
})
```

Think:
```
HTML → render_template()
  

JSON → jsonify()
```

# Summary

### Template

An HTML file that can contain dynamic Jinja2 code.

### Jinja2

The template engine used by Flask.

### `templates/`

The default directory where Flask searches for templates.

### `render_template()`

Loads a template, processes it with Jinja2, and returns the resulting HTML response.

### Jinja2 basics

```
{{ value }}     → Display value

  
{% logic %}     → Execute template logic


{# comment #}   → Template comment
```

## One-Line Definition

> **Jinja2 is Flask's template engine that allows Python data and logic to be combined with HTML to generate dynamic web pages.**
