Jinja2 conditions allow a template to **make decisions based on data**.

For example:
```
If user is logged in
    → Show Dashboard

Otherwise
    → Show Login
```
Or:

```
If product is available
    → Show "Buy Now"

Otherwise
    → Show "Out of Stock"
```
Jinja2 uses:

```
{% if condition %}

    ...
    
{% endif %}
```

---

# 1. Basic `if`

Suppose Flask sends:
```
@app.route("/")
def home():
    age = 20
    return render_template(
        "home.html",
        age=age
    )
```
Template:

```
{% if age >= 18 %}

    <p>You are an adult.</p>

{% endif %}
```

Because:

```
20 >= 18
```

is `True`, the browser receives:

```
<p>You are an adult.</p>
```

---

# 2. `if` + `else`

Sometimes we need two possibilities.
```
{% if age >= 18 %}

    <p>Adult</p>

{% else %}

    <p>Minor</p>

{% endif %}
```

If:
```
age = 20
```

Output:
```
Adult
```

If:
```
age = 15
```

Output:
```
Minor
```

---

# 3. `elif`

When there are more than two possibilities, use:
```
{% if condition %}

{% elif condition %}

{% else %}

{% endif %}
```

Example:
```
{% if age >= 60 %}

    <p>Senior</p>

{% elif age >= 18 %}

    <p>Adult</p>

{% else %}

    <p>Minor</p>

{% endif %}
```

For:
```
age = 25
```

the result is:
```
Adult
```

---

# 4. Multiple `elif`

You can have multiple `elif` blocks.

```
{% if marks >= 90 %}

    <p>Grade A+</p>

{% elif marks >= 80 %}

    <p>Grade A</p>

{% elif marks >= 70 %}

    <p>Grade B</p>

{% elif marks >= 60 %}

    <p>Grade C</p>

{% else %}

    <p>Grade F</p>

{% endif %}
```

Suppose:
```
marks = 85
```

Output:
```
Grade A
```

Jinja2 checks from top to bottom and stops at the first condition that is true.

---

# 5. Comparison Operators

Jinja2 supports common comparison operators.

|Operator|Meaning|
|---|---|
|`==`|Equal|
|`!=`|Not equal|
|`>`|Greater than|
|`<`|Less than|
|`>=`|Greater than or equal|
|`<=`|Less than or equal|

Examples:
```
{% if age == 20 %}

{% endif %}

{% if age != 20 %}

{% endif %}

{% if age > 18 %}

{% endif %}

{% if age < 18 %}

{% endif %}
```

---

# 6. Comparing Strings

Suppose:
```
role = "admin"
```

Template:
```
{% if role == "admin" %}

    <p>Admin Panel</p>

{% endif %}
```

If `role` is `"admin"`, the content is displayed.

---

# 7. `and`

You can combine multiple conditions.
```
{% if age >= 18 and verified == True %}

    <p>Access Granted</p>

{% endif %}
```

Both conditions must be true.

Conceptually:
```
age >= 18
      AND
verified == True
      ↓
   Access
```

---

# 8. `or`

`or` means at least one condition must be true.

```
{% if role == "admin" or role == "manager" %}

    <p>Management Area</p>

{% endif %}
```

If either condition is true, the content is shown.

---

# 9. `not`

`not` reverses a condition.

```
{% if not logged_in %}

    <p>Please log in.</p>

{% endif %}
```

If:
```
logged_in = False
```

then:
```
not False
=
True
```

so the message appears.

---

# 10. Checking a Boolean

Suppose:
```
logged_in = True
```

You don't need to write:
```
{% if logged_in == True %}
```

You can simply write:
```
{% if logged_in %}

    <p>Welcome!</p>

{% endif %}
```

This is cleaner.

Similarly:
```
{% if not logged_in %}

    <p>Please log in.</p>

{% endif %}
```

---

# 11. Checking Whether a Value Exists

You can simply use:
```
{% if username %}

    <p>Hello {{ username }}</p>

{% endif %}
```

If `username` contains:

```
John
```
the condition is true.

If it is empty or undefined, it is treated as false in normal Jinja usage.

---

# 12. Checking an Empty List

Suppose:
```
students = []
```

You can write:
```
{% if students %}

    <p>Students found.</p>

{% else %}

    <p>No students found.</p>

{% endif %}
```

An empty list evaluates as false.

---

# 13. Checking Whether an Item Exists

Suppose:
```
roles = ["admin", "editor", "user"]
```

You can use:
```
{% if "admin" in roles %}

    <p>Admin role exists.</p>

{% endif %}
```

Because `"admin"` is inside the list, the condition is true.

---

# 14. `not in`

You can also check that something doesn't exist.

```
{% if "guest" not in roles %}

    <p>Guest role is not available.</p>

{% endif %}
```

---

# 15. Conditions with Dictionary Data

Suppose:
```
user = {
    "name": "John",
    "age": 20,
    "active": True
}
```

You can write:
```
{% if user.active %}

    <p>User is active.</p>

{% endif %}
```

Or:
```
{% if user.age >= 18 %}

    <p>Adult user.</p>

{% endif %}
```

---

# 16. Conditions Inside Loops

This is extremely common.

Suppose:
```
students = [
    {"name": "John", "marks": 85},
    {"name": "Alice", "marks": 45},
    {"name": "Bob", "marks": 72}
]
```

Template:
```
{% for student in students %}

    <h3>{{ student.name }}</h3>

    {% if student.marks >= 50 %}

        <p>Passed</p>

    {% else %}  

        <p>Failed</p>

    {% endif %}

{% endfor %}
```

Output:
```
John
Passed

Alice
Failed

Bob
Passed
```

So you can combine:
```
Loop

 +

Condition
```

to create dynamic pages.

---

# 17. `if` + `for` Example

A more realistic example:

```
{% for product in products %}

    <div class="product">

        <h2>{{ product.name }}</h2>

        <p>Price: ₹{{ product.price }}</p>  

        {% if product.available %}

            <button>Buy Now</button>

        {% else %}
        
            <p>Out of Stock</p>

        {% endif %}
        
    </div>

{% endfor %}
```

Each product can produce different HTML depending on its data.

---

# 18. Nested Conditions

You can put an `if` inside another `if`.

```
{% if logged_in %}

    {% if is_admin %}

        <p>Admin Panel</p>

    {% else %}

        <p>User Dashboard</p>

    {% endif %}

{% else %}

    <p>Please log in.</p>

{% endif %}
```

This works, but don't create deeply nested conditions unless necessary because they quickly become difficult to read.

---

# 19. Parentheses

You can use parentheses when combining conditions.

```
{% if (age >= 18 and verified) or is_admin %}

    <p>Access Granted</p>

{% endif %}
```

This makes the intended logic clearer.

---

# 20. Python vs Jinja2 Conditions

The syntax is very similar.

### Python

```
if age >= 18:

    print("Adult")
```

### Jinja2

```
{% if age >= 18 %}

    <p>Adult</p>

{% endif %}
```

The biggest difference is that Jinja2 needs template tags:
```
{% ... %}
```

and doesn't use Python's indentation to mark the block.

---

# 21. Don't Forget `{% endif %}`

This is a very common mistake.

❌ Wrong:

```
{% if age >= 18 %}

    <p>Adult</p>
```

✅ Correct:

```
{% if age >= 18 %}

    <p>Adult</p>

{% endif %}
```

Similarly:

```
{% if ... %}

{% elif ... %}  

{% else %}

{% endif %}
```

# 22. Complete Example

### `app.py`

```
from flask import Flask, render_template


app = Flask(__name__)

  

@app.route("/")
def home():
    user = {
        "name": "John",
        "age": 20,
        "verified": True,
        "role": "admin"
    }

    return render_template(
        "home.html",
        user=user
    )

  

if __name__ == "__main__":
    app.run(debug=True)
```

### `home.html`

```
<!DOCTYPE html>
<html>
<head>
    <title>User</title>
</head>
<body>
    <h1>Hello {{ user.name }}</h1>
    
    {% if user.age >= 18 %}

        <p>Adult</p>

    {% else %}
    
        <p>Minor</p>
        
    {% endif %}

    {% if user.verified %}

        <p>Account Verified</p>

    {% else %}

        <p>Account Not Verified</p>

    {% endif %}

    {% if user.role == "admin" %}

        <a href="/admin">Admin Panel</a>
        
    {% elif user.role == "editor" %}

        <a href="/editor">Editor Panel</a>

    {% else %}

        <a href="/dashboard">Dashboard</a>

    {% endif %}

</body>
</html>
```

# 23. The Three Main Conditional Structures

### Simple condition
```
{% if condition %}

  
{% endif %}
```

### Two possibilities
```
{% if condition %}

{% else %}

{% endif %}
```

### Multiple possibilities

```
{% if condition1 %}

{% elif condition2 %}  

{% elif condition3 %}

{% else %}

{% endif %}
```

---

# Quick Reference

### Comparison

```
{% if age >= 18 %}

{% if age == 20 %}

{% if age != 20 %}
```

### Logical operators

```
{% if a and b %}

{% if a or b %}

{% if not a %}
```

### Membership

```
{% if "admin" in roles %}

{% if "guest" not in roles %}
```

### Boolean

```
{% if logged_in %}

{% if not logged_in %}
```

### Empty data

```
{% if students %}

{% else %}

    No students found.

{% endif %}
```

---

# Mental Model

Remember:

```
{% if %}       → Start decision

{% elif %}     → Try another condition  

{% else %}     → Nothing above was true

{% endif %}    → End decision
```

And:

```
{{ }}          → Display data

{% %}          → Control template logic
```

---

## One-Line Definition

> **Jinja2 conditions use `{% if %}`, `{% elif %}`, and `{% else %}` to control which parts of an HTML template are rendered based on data.**
