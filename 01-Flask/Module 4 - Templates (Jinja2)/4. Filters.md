Jinja2 **filters** allow you to **modify or transform data before displaying it** in a template.

The basic syntax is:

```
{{ value | filter }}
```

The `|` symbol is called the **pipe**.

Think of a filter as a small processing step:

```
Original Data
     │
     ▼
   Filter
     │
     ▼
Modified Data
     │
     ▼
  Display
```

For example:

```
{{ name | upper }}
```

If:

```
name = "john"
```

the output becomes:

```
JOHN
```

---

# 1. Why Do We Need Filters?

Suppose Flask sends:

```
name = "john"
```

but you want to display:

```
JOHN
```

You could modify the value in Python:

```
name = name.upper()
```

But if the transformation is only needed for presentation, you can do it directly in the template:

```
{{ name | upper }}
```

This keeps your Python logic cleaner.

---

# 2. Basic Filter Syntax

```
{{ value | filter }}
```

Example:

```
{{ name | upper }}
```

Multiple filters can be chained:

```
{{ name | upper | trim }}
```

The processing happens from left to right:

```
name
 ↓
upper
 ↓
trim
 ↓
output
```

---

# 3. `upper`

Converts text to uppercase.

```
{{ name | upper }}
```

Input:

```
john doe
```

Output:

```
JOHN DOE
```

---

# 4. `lower`

Converts text to lowercase.

```
{{ name | lower }}
```

Input:

```
JOHN DOE
```

Output:

```
john doe
```

---

# 5. `capitalize`

Makes the first character uppercase and the remaining characters lowercase.

```
{{ name | capitalize }}
```

Input:

```
john DOE
```

Output:

```
John doe
```

Be careful: `capitalize` does **not** mean "capitalize every word."

---

# 6. `title`

Capitalizes each word.

```
{{ name | title }}
```

Input:

```
john doe
```

Output:

```
John Doe
```

---

# 7. `trim`

Removes whitespace from the beginning and end of a string.

```
{{ name | trim }}
```

Input:

```
"   John   "
```

Output:

```
"John"
```

It doesn't remove spaces between words.

```
"John    Doe"
```

remains:

```
"John    Doe"
```

---

# 8. `default`

`default` lets you provide a fallback value when a variable is undefined.

```
{{ username | default("Guest") }}
```

If `username` exists:

```
John
```

Output:

```
John
```

If `username` is undefined:

```
Guest
```

---

## `default` With Empty Values

You can also tell Jinja2 to use the default when the value is false-like:

```
{{ username | default("Guest", true) }}
```

This can handle values such as an empty string.

---

# 9. `length`

Returns the number of items or characters.

For a string:

```
{{ name | length }}
```

If:

```
John
```

Output:

```
4
```

For a list:

```
subjects = ["Python", "Java", "SQL"]

{{ subjects | length }}
```

Output:

```
3
```

---

# 10. `first`

Returns the first item.

```
{{ subjects | first }}
```

If:

```
subjects = ["Python", "Java", "SQL"]
```

Output:

```
Python
```

---

# 11. `last`

Returns the last item.

```
{{ subjects | last }}
```

Output:

```
SQL
```

---

# 12. `join`

Combines list elements into a string.

Suppose:

```
subjects = ["Python", "Java", "SQL"]
```

You can write:

```
{{ subjects | join(", ") }}
```

Output:

```
Python, Java, SQL
```

Without specifying a separator:

```
{{ subjects | join }}
```

the elements are joined directly.

---

# 13. `replace`

Replaces part of a string.

```
{{ name | replace("John", "Alex") }}
```

Input:

```
Hello John
```

Output:

```
Hello Alex
```

Syntax:

```
{{ value | replace("old", "new") }}
```

---

# 14. `truncate`

Shortens long text.

```
{{ description | truncate(50) }}
```

Useful when displaying long descriptions, summaries, or previews.

For example:

This is a very long description containing lots of...

instead of displaying the entire paragraph.

---

# 15. `round`

Rounds a number.

Suppose:

```
price = 99.87654
```

You can use:

```
{{ price | round }}
```

Output:

```
100
```

You can specify decimal places:

```
{{ price | round(2) }}
```

Output:

```
99.88
```

---

# 16. `int`

Converts a value to an integer.

```
{{ value | int }}
```

For example:

```
"25"
```

can become:

```
25
```

You can also provide a default:

```
{{ value | int(0) }}
```

---

# 17. `float`

Converts a value to a floating-point number.

```
{{ value | float }}
```

Example:

```
"25.5"
```

becomes:

```
25.5
```

---

# 18. `string`

Converts a value into a string representation.

```
{{ value | string }}
```

This can be useful when you explicitly need string-like output.

---

# 19. `abs`

Returns the absolute value.

```
{{ number | abs }}
```

If:

```
-25
```

Output:

```
25
```

---

# 20. `sort`

Sorts a sequence.

Suppose:

```
numbers = [5, 2, 8, 1, 3]
```

Template:

```
{{ numbers | sort }}
```

Result:

```
[1, 2, 3, 5, 8]
```

---

# 21. `reverse`

Reverses a sequence.

```
{{ subjects | reverse | list }}
```

For:

```
["Python", "Java", "SQL"]
```

you can obtain the reversed sequence:

```
SQL

Java

Python
```

The `list` filter is useful here because `reverse` produces an iterable.

---

# 22. `list`

Converts an iterable into a list.

```
{{ value | list }}
```

This becomes particularly useful when combining filters such as:

```
{{ subjects | reverse | list }}
```

---

# 23. `dictsort`

Sorts dictionary items.

Suppose:

```
marks = {
    "John": 80,
    "Alice": 95,
    "Bob": 70
}
```

You can use:

```
{% for name, mark in marks | dictsort %}

    <p>{{ name }}: {{ mark }}</p>

{% endfor %}
```

The dictionary entries will be sorted by key by default.

---

# 24. Filters With Arguments

Some filters accept additional values.

For example:

```
{{ name | replace("John", "Alex") }}
```

Here:

```
Filter:
replace

Arguments:
"John"
"Alex"
```

Another:

```
{{ description | truncate(50) }}
```

Argument:

```
50
```

So filters aren't always just:

```
{{ value | filter }}
```

They can also be:

```
{{ value | filter(argument) }}
```

---

# 25. Chaining Filters

This is one of the most useful features.

You can apply multiple filters:

```
{{ name | trim | upper }}
```

Suppose:

```
"   john   "
```

Processing:

```
"   john   "
      ↓
    trim
      ↓
   "john"
      ↓
    upper
      ↓
   "JOHN"
```

Final output:

```
JOHN
```

---

# 26. Another Chaining Example

```
{{ name | trim | lower | title }}
```

Input:

```
"   JOHN DOE   "
```

Processing:

```
trim
 ↓
"JOHN DOE"

lower
 ↓
"john doe"

title
 ↓
"John Doe"
```
Final:

```
John Doe
```

---

# 27. Filters With Variables

Filters can work on variables just like literal values.

Python:

```
name = "john"
```

Template:

```
{{ name | upper }}
```

Or:

```
price = 99.876

₹{{ price | round(2) }}
```

Output:

```
₹99.88
```

---

# 28. Filters Inside Loops

Filters become especially useful with loops.

Python:

```
students = [
    "john",
    "alice",
    "bob"
]
```

Template:

```
{% for student in students %}

    <p>{{ student | title }}</p>

{% endfor %}
```

Output:

```
John
Alice
Bob
```

---

# 29. Filters Inside Conditions

You can also use filters inside an `if`.

```
{% if name | length > 10 %}

    <p>Name is long.</p>  

{% endif %}
```

The value is filtered first:

```
name
 ↓
length
 ↓
comparison
```

---

# 30. Filters vs Functions

This distinction is useful.

A normal Python function might look like:

```
len(name)
```

A Jinja2 filter looks like:

```
{{ name | length }}
```

Another example:

```
name.upper()
```

becomes:

```
{{ name | upper }}
```

So conceptually:

Python:

```
value.method()
```

Jinja2:

```
{{ value | filter }}
```

They aren't literally the same mechanism, but this mental model makes filters easy to understand.

---

# 31. Filters Do Not Change the Original Python Variable

Suppose:

```
name = "john"
```

Template:

```
{{ name | upper }}
```

The output is:

```
JOHN
```

But the Python variable itself is still:

```
john
```

The filter transforms the value **for template rendering**.

Think of it as:

```
Original data
     │
     ├─────────────── remains unchanged
     │
     ▼
   Filter
     │
     ▼
Displayed result
```
---

# 32. Complete Example

### `app.py`

```
from flask import Flask, render_template

  
app = Flask(__name__)

  
@app.route("/")
def home():
    name = "   john doe   "

    subjects = [
        "Python",
        "Java",
        "SQL"
    ]

    price = 99.8765

    return render_template(
        "home.html",
        name=name,
        subjects=subjects,
        price=price
    )

  

if __name__ == "__main__":
    app.run(debug=True)
```

### `home.html`

```
<!DOCTYPE html>
<html>
<head>
    <title>Filters</title>
</head>
<body>

    <h1>{{ name | trim | title }}</h1>  

    <p>Subjects: {{ subjects | join(", ") }}</p>

    <p>Total Subjects: {{ subjects | length }}</p>

    <p>Price: {{ price | round(2) }}</p>

</body>
</html>
```

Output:

```
John Doe

Subjects: Python, Java, SQL

Total Subjects: 3

Price: 99.88
```

# 34. The Most Important Syntax

Remember these three patterns:

### Basic

```
{{ value | filter }}
```

### Filter with argument

```
{{ value | filter(argument) }}
```

### Multiple filters

```
{{ value | filter1 | filter2 | filter3 }}
```

---

# 35. A Simple Mental Model

Imagine a little data-processing conveyor belt:

```
"   john doe   "
       │
       ▼
     trim
       │
       ▼
"john doe"
       │
       ▼
     title
       │
       ▼
"John Doe"
```

In Jinja2:

```
{{ name | trim | title }}
```

That's the heart of filters.

---

## One-Line Definition

> **Jinja2 filters transform or format values inside templates using the `|` operator before those values are displayed.**
