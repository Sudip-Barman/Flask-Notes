Jinja2 loops allow you to **repeat HTML elements for multiple pieces of data**.

For example, suppose Flask gives us:
```
students = ["John", "Alice", "Bob"]
```

Instead of manually writing:
```
<li>John</li>

<li>Alice</li>

<li>Bob</li>
```

we can use a Jinja2 `for` loop.

---

# 1. Basic `for` Loop

Jinja2 uses:
```
{% for item in items %}
    ...

{% endfor %}
```

Example:
```
<ul>
    {% for student in students %}

        <li>{{ student }}</li>

    {% endfor %}
</ul>
```

If:
```
students = ["John", "Alice", "Bob"]
```

the generated HTML becomes approximately:

<ul>

    <li>John</li>

    <li>Alice</li>

    <li>Bob</li>

</ul>

The browser doesn't see the Jinja2 loop. It receives the final HTML.

---

# 2. Complete Flask Example

### `app.py`

```
from flask import Flask, render_template

app = Flask(__name__)

  
@app.route("/")
def home():
    students = [
        "John",
        "Alice",
        "Bob"
    ]

    return render_template(
        "home.html",
        students=students
    )


if __name__ == "__main__":
    app.run(debug=True)
```

### `templates/home.html`

```
<!DOCTYPE html>
<html>
<head>
    <title>Students</title>
</head>
<body>
    <h1>Students</h1>
    <ul>
        {% for student in students %}
            <li>{{ student }}</li>
        {% endfor %}
    </ul>
</body>
</html>
```

Result:
```
Students

• John

• Alice

• Bob
```

---

# 3. Understanding the Loop

This:
```
{% for student in students %}
```

means:

> Take each item from `students` and temporarily call it `student`.

Suppose:
```
students = ["John", "Alice", "Bob"]
```

Jinja2 effectively goes through:

First iteration:
```
student = "John"
```

Second iteration:
```
student = "Alice"
```

  

Third iteration:
```
student = "Bob"
```

Then:
```
{% endfor %}
```

marks the end of the loop.

---

# 4. Looping Through Numbers

You can use `range()`:
```
{% for i in range(5) %}
    <p>{{ i }}</p>
{% endfor %}
```

Output:
```
0

1

2

3

4
```

Remember:
```
range(5)
````

starts at `0` and stops before `5`.

---

# 5. Starting From a Different Number

```
{% for i in range(1, 6) %}

    <p>{{ i }}</p>

{% endfor %}
```

Output:
```
1

2

3

4

5
```

---

# 6. Looping Through a Dictionary

Suppose:
```
student = {
    "name": "John",
    "age": 20,
    "course": "BCA"
}
```

You can loop through it:

```
{% for key, value in student.items() %}

    <p>{{ key }}: {{ value }}</p>

{% endfor %}
```

Output:
```
name: John
age: 20
course: BCA
```

---

students = [

# 8. Creating a Table

Loops become especially useful when displaying database results.
```
<table>
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>
    
    {% for student in students %}
    
    <tr>
        <td>{{ student.name }}</td>
        <td>{{ student.age }}</td>
    </tr>

    {% endfor %}

</table>
```

Instead of creating hundreds of `<tr>` elements manually, Jinja2 generates them from your data.

# 9. Loop Variables

Jinja2 provides a special object called:
```
loop
```

It gives you information about the current iteration.

For example:
```
{% for student in students %}

    {{ loop.index }}. {{ student }}

{% endfor %}
```

If:
```
students = ["John", "Alice", "Bob"]
```

Output:
```
1. John

2. Alice

3. Bob
```

---

# 10. `loop.index`

`loop.index` starts at **1**.

```
{% for student in students %}

    {{ loop.index }} - {{ student }}

{% endfor %}
```

Result:
```
1 - John

2 - Alice

3 - Bob
```

---

# 11. `loop.index0`

`loop.index0` starts at **0**.

```
{% for student in students %}

    {{ loop.index0 }} - {{ student }}

{% endfor %}
```

Result:
```
0 - John

1 - Alice

2 - Bob
```

This is useful when you want Python-style indexing.

---

# 12. `loop.first`

`loop.first` tells you whether the current iteration is the first one.

```
{% for student in students %}

    {% if loop.first %}

        <strong>First Student:</strong>

    {% endif %}

    {{ student }}

{% endfor %}
```

Result:
```
First Student: John

Alice

Bob
```

---

# 13. `loop.last`

Similarly:

```
{% for student in students %}

    {{ student }}  

    {% if loop.last %}

        <strong>Last Student</strong>

    {% endif %}

{% endfor %}
```

Result:

```
John

Alice

Bob 

Last Student
```

---

# 14. `loop.length`

Returns the total number of items.

```
{% for student in students %}

    {{ student }}

    <p>
        Total: {{ loop.length }}
    </p>

{% endfor %}
```

If there are 3 students:
```
Total: 3
```

---

# 15. `loop.revindex`

`loop.revindex` counts backward starting from `1`.

For:
```
students = ["John", "Alice", "Bob"]

{% for student in students %}

    {{ student }} - {{ loop.revindex }}

{% endfor %}
```

Result:
```
John - 3

Alice - 2

Bob - 1
```

---

# 16. `loop.revindex0`

Starts from `0` when counting backward.
```
{% for student in students %}

    {{ student }} - {{ loop.revindex0 }}

{% endfor %}
```

Result:
```
John - 2

Alice - 1

Bob - 0
```
---

# 17. Important Loop Variables

|Variable|Meaning|
|---|---|
|`loop.index`|Current index starting at 1|
|`loop.index0`|Current index starting at 0|
|`loop.revindex`|Reverse index starting at 1|
|`loop.revindex0`|Reverse index starting at 0|
|`loop.first`|`True` for first iteration|
|`loop.last`|`True` for last iteration|
|`loop.length`|Total number of items|

The most commonly useful ones are:
```
loop.index

loop.first

loop.last

loop.length
```

# 18. Checking Whether a List Is Empty

Suppose:
```
students = []
```

A loop simply won't produce anything:
```
{% for student in students %}

    <p>{{ student }}</p>

{% endfor %}
```

The page will contain nothing from the loop.

Jinja2 provides a convenient `else` with loops:

```
{% for student in students %}

    <p>{{ student }}</p>

{% else %}  

    <p>No students found.</p>

{% endfor %}
```

If the list is empty:
```
No students found.
```

This is very useful when displaying database results.

# 19. Nested Loops

You can put one loop inside another.

Example:
```
classes = [
    {
        "name": "Class A",
        "students": ["John", "Alice"]
    },
    {
        "name": "Class B",
        "students": ["Bob", "David"]
    }
]
```

Template:
```
{% for class in classes %}

    <h2>{{ class.name }}</h2>  

    {% for student in class.students %}

        <p>{{ student }}</p>

    {% endfor %}

{% endfor %}
```

Result:

```
Class A
    John
    Alice
  
Class B
    Bob
    David
```

# 20. Loop + HTML

Loops aren't limited to text.

You can generate cards:
```
{% for product in products %}

<div class="product-card">

    <h2>{{ product.name }}</h2>

    <p>₹{{ product.price }}</p>

    <button>View</button>  

</div>

{% endfor %}
```

This is how dynamic pages can generate dozens or thousands of similar UI elements from data.

# 25. Important Syntax Difference

Remember:

### Display something

```
{{ student }}
```

### Control a loop

```
{% for student in students %}
```

### End the loop

```
{% endfor %}
```

So:
```
{% for student in students %}

    {{ student }}

{% endfor %}
```

means:
```
START LOOP
   ↓
Display student
   ↓
Repeat
   ↓
END LOOP
```

# The Big Picture

You now have:

Python

│

│ students = [...]

│

▼

render_template()

│

▼

Jinja2

│

│ {% for student in students %}

│

│     {{ student.name }}

│

│ {% endfor %}

│

▼

Generated HTML

│

▼

Browser

This becomes especially powerful later when Flask retrieves records from **MySQL**.

For example:

MySQL

  ↓

SQLAlchemy

  ↓

Python objects

  ↓

render_template()

  ↓

Jinja2 loop

  ↓

HTML table

That's how a database containing 1,000 records can become a dynamic web page without manually writing 1,000 HTML rows.

> **Jinja2 loops use `{% for %}` and `{% endfor %}` to repeatedly generate HTML from a collection of data.**
