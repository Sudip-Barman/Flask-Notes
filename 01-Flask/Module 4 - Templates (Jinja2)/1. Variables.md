A **Jinja2 variable** allows you to take data from Flask/Python and display it inside an HTML template.

The basic syntax is:
```
{{ variable }}
```

Think of it as:

```
Python variable
      ↓
render_template()
      ↓
Jinja2 variable
      ↓
HTML
      ↓
Browser
```

---

# 1. Basic Variable

Suppose Flask has:
```
name = "John"
```

Pass it to the template:
```
@app.route("/")
def home():
    name = "John"
    return render_template(
        "home.html",
        name=name
    )
```

In `home.html`:

```
<h1>Hello, {{ name }}</h1>
```

The browser receives:
```
<h1>Hello, John</h1>
```

Jinja2 replaced:
```
{{ name }}
```

with:
```
John
```

---

# 2. Variables Are Passed Through `render_template()`

This is important.

Suppose you have:

```
name = "John"
```

but you don't pass it:

```
return render_template("home.html")
```

Then the template doesn't automatically know about your local Python variable.

You need:

```
return render_template(
    "home.html",
    name=name
)
```

The general pattern is:

```
render_template(
    "template.html",
    variable_name=value
)
```

For example:
```
name = "John"
age = 20
city = "Delhi"

return render_template(
    "home.html",
    name=name,
    age=age,
    city=city
)
```

# 3. Displaying Different Data Types

Jinja2 can display many Python data types.

### String
```
name = "John"

{{ name }}
```

Output:
```
John
```

### Integer
```
age = 20

{{ age }}
```

Output:
```
20
```

### Float
```
price = 99.99

{{ price }}
```

Output:
```
99.99
```

### Boolean
```
active = True

{{ active }}
```

Output:
```
True
```
### List
```
colors = ["Red", "Blue", "Green"]
```

You can access an item:
```
{{ colors[0] }}
```

Output:
```
Red
```

### Dictionary
```
student = {
    "name": "John",
    "age": 20
}
```

You can access:
```
{{ student["name"] }}
```

or:
```
{{ student.name }}
```

Both can produce:
```
John
```

---

# 4. Variables Inside HTML

You can put variables almost anywhere in HTML.

```
<h1>{{ title }}</h1>

<p>Name: {{ name }}</p>

<p>Age: {{ age }}</p>

<p>City: {{ city }}</p>
```

You can also put them inside attributes:

```
<img src="{{ image_url }}">
```

or:
```
<a href="{{ website }}">
    Visit Website
</a>
```
---

# 5. Expressions

Jinja2 doesn't only display variables.

You can perform expressions inside:
```
{{ }}
```

For example:
```
<p>{{ 10 + 5 }}</p>
```

Output:
```
15
```

---

### Arithmetic
```
{{ 10 + 5 }}

{{ 10 - 5 }}

{{ 10 * 5 }}

{{ 10 / 5 }}
```

You can also use variables:
```
price = 100

quantity = 3

<p>Total: {{ price * quantity }}</p>
```

Output:

```
Total: 300
```

---

# 6. String Operations

Suppose:

```
first_name = "John"

last_name = "Doe"

You can concatenate:

{{ first_name + " " + last_name }}
```

Output:

```
John Doe
```

subjects = [

# 9. Nested Data

Python:

```
student = {
    "name": "John",
    "address": {
        "city": "Delhi",
        "country": "India"
    }
}
```

Template:

```
{{ student.name }}
```

Output:

```
John
```

Nested:

```
{{ student.address.city }}
```

Output:

```
Delhi
```

You can also use brackets:

```
{{ student["address"]["city"] }}
```

# 10. Passing an Object

Jinja2 can also access object attributes.

Python:
```
class Student:

  

    def __init__(self, name, age):

        self.name = name

        self.age = age

  

  

student = Student("John", 20)
```

Pass it:

```
return render_template(
    "student.html",
    student=student
)
```

Template:
```
<h1>{{ student.name }}</h1>

<p>{{ student.age }}</p>
```

Output:
```
John

20
```
``
This becomes especially useful when working with **SQLAlchemy models**, which we'll encounter later in the MySQL/database modules.

# 11. Missing Variables

Suppose your Python code sends:

name = "John"

but your template contains:

{{ username }}

There is no `username`.

Jinja2 generally renders an undefined variable as an empty value rather than crashing immediately.

For example:

<h1>Hello {{ username }}</h1>

may result in:

<h1>Hello </h1>

This can make debugging confusing.

Later, we'll learn better ways to handle undefined variables.

---

# 12. `None`

Python:

name = None

Template:

{{ name }}

Usually produces an empty-looking value.

If you need to display something when data is missing, **filters** are useful.

For example:

{{ name | default("Guest") }}

We'll study filters separately.

# 13. Variables in Attributes

This is extremely common.

Python:

image_url = "/static/images/profile.jpg"

Template:

<img src="{{ image_url }}">

Generated HTML:

<img src="/static/images/profile.jpg">

Another example:

page_url = "/about"

<a href="{{ page_url }}">About</a>

Generated:

<a href="/about">About</a>

---

# 14. Variables in CSS Classes

You can even dynamically generate a class:

status = "active"

<div class="user-{{ status }}">

    User

</div>

Generated HTML:

<div class="user-active">

    User

</div>

---

# 15. Variables Are Not Python Code

This is important.

Inside:

{{ }}

you can use expressions supported by Jinja2, but you are **not writing arbitrary Python**.

For example, don't think:

{{ import os }}

means you can execute Python there.

Jinja2 has its own template language.

You'll use:

{{ ... }}   → expressions

{% ... %}   → template statements

rather than putting normal Python code directly into HTML.

---

# 16. A Complete Example

### `app.py`

from flask import Flask, render_template

  

app = Flask(__name__)

  

@app.route("/")

def home():

  

    student = {

        "name": "John",

        "age": 20,

        "course": "BCA",

        "subjects": [

            "Python",

            "Java",

            "SQL"

        ]

    }

  

    return render_template(

        "home.html",

        student=student

    )

  

if __name__ == "__main__":

    app.run(debug=True)

### `templates/home.html`

<!DOCTYPE html>

<html>

  

<head>

    <title>Student</title>

</head>

  

<body>

  

    <h1>{{ student.name }}</h1>

  

    <p>Age: {{ student.age }}</p>

  

    <p>Course: {{ student.course }}</p>

  

    <p>First Subject: {{ student.subjects[0] }}</p>

  

</body>

  

</html>

The browser receives:

John

  

Age: 20

  

Course: BCA

  

First Subject: Python

---

# The Most Important Concept

Remember the difference between these:

### Python

name = "John"

### Passing data

render_template(

    "home.html",

    name=name

)

### Jinja2

{{ name }}

### Final HTML

<h1>John</h1>

So the pipeline is:

Python Variable

      ↓

render_template()

      ↓

Jinja2

      ↓

{{ variable }}

      ↓

Generated HTML

      ↓

Browser

# Quick Reference

|Syntax|Purpose|
|---|---|
|`{{ name }}`|Display a variable|
|`{{ user.name }}`|Access an attribute/key|
|`{{ items[0] }}`|Access list item|
|`{{ price * quantity }}`|Expression|
|`{{ a + b }}`|Calculation|
|`{{ name \| default("Guest") }}`|Default value|

---

## One-Line Definition

> **Jinja2 variables are placeholders written using `{{ }}` that allow data passed from Flask to be displayed dynamically inside an HTML template.**
