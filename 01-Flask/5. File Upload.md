## What Happens During File Upload?

Suppose a user selects:

```
notes.pdf
```

and clicks:

```
Upload
```

The browser sends:

```
POST /upload

File: notes.pdf
```

Flask receives it using:

```
request.files
```

Remember:

```
request.args       -> URL Data
request.form       -> Form Data
request.get_json() -> JSON Data
request.files      -> Files
```

---

## First Example

### HTML

```
<form method="POST"
      enctype="multipart/form-data">

    <input
        type="file"
        name="myfile"
    >

    <button>
        Upload
    </button>

</form>
```

Notice:

```
enctype="multipart/form-data"
```

This is REQUIRED for file uploads.

Without it:

```
request.files
```

will be empty.

---

## Flask

```
from flask import Flask, request

app = Flask(__name__)

@app.route("/", methods=["GET", "POST"])
def upload():

    if request.method == "POST":

        file = request.files["myfile"]

        return file.filename

    return """
    <form method="POST"
          enctype="multipart/form-data">

        <input type="file"
               name="myfile">

        <button>Upload</button>

    </form>
    """

if __name__ == "__main__":
    app.run(debug=True)
```

## `request.files`

Think of it as a dictionary.

```
request.files
```

Example:

```
{
    "myfile": FileStorage(...)
}
```

You can access:

```
file = request.files["myfile"]
```

or:

```
file = request.files.get("myfile")
```

---

## Saving Files

Printing the filename is useful, but usually we save the file.

```
file.save("notes.pdf")
```

Example:

```
@app.route("/", methods=["POST"])
def upload():

    file = request.files["myfile"]

    file.save(file.filename)

    return "Uploaded Successfully!"
```

If the user uploads:

```
resume.pdf
```

Flask creates:

```
project/
│
├── app.py
└── resume.pdf
```

---

## Better Approach

Create an `uploads` folder.

```
project/
│
├── app.py
└── uploads/
```

Code:

```
import os

UPLOAD_FOLDER = "uploads"

@app.route("/", methods=["POST"])
def upload():

    file = request.files["myfile"]

    path = os.path.join(
        UPLOAD_FOLDER,
        file.filename
    )

    file.save(path)

    return "Done"
```

## Multiple Files

HTML:

```
<input
    type="file"
    name="files"
    multiple
>
```

Flask:

```
files = request.files.getlist(
    "files"
)

for file in files:
    file.save(file.filename)
```

User selects:

```
notes.pdf
resume.pdf
image.png
```

Flask saves all three files.

## File Validation

Suppose you only want PDFs.

```
file = request.files["myfile"]

if file.filename.endswith(".pdf"):

    file.save(file.filename)

    return "PDF Uploaded"

return "Only PDFs allowed"
```

## Allowed Extensions

```
ALLOWED = {
    "pdf",
    "jpg",
    "png"
}
```

Example:

```
def allowed(filename):

    return "." in filename and \
           filename.rsplit(
               ".",
               1
           )[1].lower() in ALLOWED
```

Usage:

```
if allowed(file.filename):
    file.save(...)
```

## Important: `secure_filename`

Suppose someone uploads:

```
../../../hack.py
```

This can be dangerous.

Flask provides:

```
from werkzeug.utils import secure_filename
```

Example:

```
filename = secure_filename(
    file.filename
)

file.save(filename)
```

Input:

```
../../../hack.py
```

Output:

```
hack.py
```

Always use:

```
secure_filename()
```

for production applications.

---

## Complete Example

```
from flask import Flask, request
from werkzeug.utils import secure_filename

app = Flask(__name__)

@app.route("/", methods=["GET", "POST"])
def upload():

    if request.method == "POST":

        file = request.files["myfile"]

        filename = secure_filename(
            file.filename
        )

        file.save(filename)

        return "Uploaded!"

    return """
    <form method="POST"
          enctype="multipart/form-data">

        <input
            type="file"
            name="myfile"
        >

        <button>
            Upload
        </button>
    """

if __name__ == "__main__":
    app.run(debug=True)
```

## Common Mistakes

### ❌ Forgetting `enctype`

Wrong:

```
<form method="POST">
```

Correct:

```
<form method="POST"
      enctype="multipart/form-data">
```

---

### ❌ Forgetting POST

Wrong:

```
@app.route("/")
```

Correct:

```
@app.route(
    "/",
    methods=["GET", "POST"]
)
```

---

### ❌ Not Checking Empty File

```
if file.filename == "":
    return "No File Selected"
```

---

### ❌ Not Using `secure_filename`

Wrong:

```
file.save(file.filename)
```

Better:

```
file.save(
    secure_filename(
        file.filename
    )
)
```
