File upload allows a user to send a file from their device to your Flask application.

Examples:

- Profile pictures
- PDFs
- Documents
- Images
- CSV files
- Videos
- Other permitted files

The basic flow is:

```
User selects file
       ↓
HTML form
       ↓
POST request
       ↓
Flask
       ↓
request.files
       ↓
Validate file
       ↓
Save / process file
```

This is different from ordinary form data.

---

# 1. Normal Form Data vs File Upload

For normal form fields:

```
<input type="text" name="username">
```

Flask reads:

```
request.form
```

For a file:

```
<input type="file" name="document">
```

Flask reads:

```
request.files
```

So remember:

```
Text input
    ↓
request.form

Uploaded file
    ↓
request.files
```

---

# 2. Creating a File Upload Form

A file upload form requires two important things.

### `method="POST"`

```
<form method="POST">
```

### `enctype="multipart/form-data"`

```
<form
    method="POST"
    enctype="multipart/form-data"
>
```

Complete example:

```
<!DOCTYPE html>

<html>

<head>
    <title>Upload File</title>
</head>

<body>

    <h1>Upload File</h1>

    <form
        method="POST"
        action="/upload"
        enctype="multipart/form-data"
    >

        <input
            type="file"
            name="document"
        >

        <button type="submit">
            Upload
        </button>

    </form>

</body>

</html>
```

The `enctype` is extremely important.

Without:

```
enctype="multipart/form-data"
```

the browser won't send the file in the way Flask expects for a multipart file upload.

---

# 3. Flask Route

Now create the Flask route:

```
from flask import Flask, request

app = Flask(__name__)


@app.route("/upload", methods=["POST"])
def upload():

    file = request.files.get("document")

    if not file:
        return "No file selected"

    return f"Received: {file.filename}"


if __name__ == "__main__":
    app.run(debug=True)
```

If the user selects:

```
report.pdf
```

then:

```
file.filename
```

contains:

```
report.pdf
```

# 4. `request.files`

This is the key Flask object for uploaded files.

Suppose your HTML has:

```
<input type="file" name="document">
```

Flask receives the file through:

```
request.files
```

And you can retrieve it with:

```
file = request.files.get("document")
```

The relationship is:

```
HTML
│
└── <input type="file" name="document">
                    │
                    ▼
                 Flask
                    │
                    ▼
            request.files
                    │
                    ▼
      request.files.get("document")
```

---

# 5. The Uploaded File Object

The variable:

```
file
```

is not just a filename.

It is a Flask/Werkzeug uploaded-file object.

It provides useful information and methods.

For example:

```
file.filename
```

Gets the original filename.

```
file.content_type
```

Gets the MIME/content type supplied for the upload.

```
file.save(...)
```

Saves the uploaded file.

You can also work with its file stream when you need to process the contents directly.

# 6. Saving the File

Create a folder:

```
project/
│
├── app.py
│
├── templates/
│   └── upload.html
│
└── uploads/
```

Then:

```
from flask import Flask, request

app = Flask(__name__)


@app.route("/upload", methods=["POST"])
def upload():

    file = request.files.get("document")

    if not file:
        return "No file selected"

    file.save("uploads/" + file.filename)

    return "File uploaded successfully"
```

If the user uploads:

```
report.pdf
```

the file is saved as:

```
uploads/report.pdf
```

---

# 7. ⚠️ Don't Directly Trust `file.filename`

This is extremely important.

Avoid blindly doing:

```
file.save("uploads/" + file.filename)
```

because filenames are controlled by the user.

A safer approach is to use Flask/Werkzeug's:

```
secure_filename()
```

Import it:

```
from werkzeug.utils import secure_filename
```

Then:

```
filename = secure_filename(file.filename)
```

and:

```
file.save("uploads/" + filename)
```

---

# 8. `secure_filename()`

Suppose the uploaded filename is something strange or contains path-related characters.

You should not blindly use it as a filesystem path.

Instead:

```
filename = secure_filename(file.filename)
```

For example, an unsafe-looking filename can be transformed into a safer filesystem filename.

Then:

```
file.save("uploads/" + filename)
```

This helps prevent filename/path manipulation.

---

# 9. Complete Basic Upload

```
from flask import Flask, request
from werkzeug.utils import secure_filename

app = Flask(__name__)


@app.route("/upload", methods=["POST"])
def upload():

    file = request.files.get("document")

    if not file:
        return "No file selected"

    if file.filename == "":
        return "No file selected"

    filename = secure_filename(file.filename)

    file.save("uploads/" + filename)

    return "File uploaded successfully"


if __name__ == "__main__":
    app.run(debug=True)
```

This is a good basic starting point.

---

# 10. Why Check `filename == ""`?

This is an important detail.

Consider:

```
file = request.files.get("document")
```

The file object may exist even when the user didn't actually select a file.

Therefore:

```
if not file:
```

is not always enough.

Also check:

```
if file.filename == "":
```

So the common pattern is:

```
if not file or file.filename == "":
    return "No file selected"
```

---

# 11. Restrict File Extensions

Suppose your application only accepts:

```
jpg
jpeg
png
```

You can define:

```
ALLOWED_EXTENSIONS = {
    "jpg",
    "jpeg",
    "png"
}
```

Then create a helper:

```
def allowed_file(filename):

    return (
        "." in filename
        and filename.rsplit(".", 1)[1].lower()
        in ALLOWED_EXTENSIONS
    )
```

Then:

```
if not allowed_file(file.filename):
    return "File type not allowed"
```

---

# 12. Understanding `rsplit()`

This:

```
filename.rsplit(".", 1)
```

splits the filename from the **right side**, at most once.

For:

```
report.pdf
```

you get roughly:

```
["report", "pdf"]
```

Then:

```
filename.rsplit(".", 1)[1]
```

gets:

```
pdf
```

And:

```
.lower()
```

converts:

```
PDF
```

to:

```
pdf
```

So:

```
extension = filename.rsplit(".", 1)[1].lower()
```

gets the extension.

---

# 13. Complete Extension Validation

```
from flask import Flask, request
from werkzeug.utils import secure_filename

app = Flask(__name__)

ALLOWED_EXTENSIONS = {
    "jpg",
    "jpeg",
    "png"
}


def allowed_file(filename):

    return (
        "." in filename
        and filename.rsplit(".", 1)[1].lower()
        in ALLOWED_EXTENSIONS
    )


@app.route("/upload", methods=["POST"])
def upload():

    file = request.files.get("document")

    if not file or file.filename == "":
        return "No file selected"

    if not allowed_file(file.filename):
        return "File type not allowed"

    filename = secure_filename(file.filename)

    file.save("uploads/" + filename)

    return "File uploaded successfully"
```

---

# 14. File Extension Is Not Enough

This is an important security concept.

Suppose you allow:

```
jpg
png
pdf
```

Checking the filename extension alone doesn't guarantee that the file's actual contents match the extension.

For example:

```
something.jpg
```

could contain something completely different.

Therefore, for serious applications, file validation can involve:

```
Filename
   ↓
Extension check
   ↓
MIME/content-type check
   ↓
Actual file-content validation
   ↓
Size limit
   ↓
Safe storage
```

The exact checks depend on the type of file you're accepting.

---

# 15. File Size Limit

A user could upload a gigantic file.

For example:

```
5 GB
```

You probably don't want your Flask server accepting that accidentally.

Flask provides:

```
app.config["MAX_CONTENT_LENGTH"]
```

For example:

```
app.config["MAX_CONTENT_LENGTH"] = 16 * 1024 * 1024
```

This means:

```
16 MB
```

because:

```
16 × 1024 × 1024 bytes
```

Now Flask rejects requests exceeding the configured maximum request size.

---

# 16. Complete Safer Example

```
from flask import Flask, request
from werkzeug.utils import secure_filename
import os

app = Flask(__name__)

app.config["MAX_CONTENT_LENGTH"] = 16 * 1024 * 1024

UPLOAD_FOLDER = "uploads"

ALLOWED_EXTENSIONS = {
    "jpg",
    "jpeg",
    "png",
    "pdf"
}


def allowed_file(filename):

    return (
        "." in filename
        and filename.rsplit(".", 1)[1].lower()
        in ALLOWED_EXTENSIONS
    )


@app.route("/upload", methods=["POST"])
def upload():

    file = request.files.get("document")

    if not file or file.filename == "":
        return "No file selected"

    if not allowed_file(file.filename):
        return "File type not allowed"

    filename = secure_filename(file.filename)

    os.makedirs(UPLOAD_FOLDER, exist_ok=True)

    file.save(
        os.path.join(UPLOAD_FOLDER, filename)
    )

    return "File uploaded successfully"
```

---

# 17. Why Use `os.path.join()`?

Instead of:

```
"uploads/" + filename
```

use:

```
os.path.join("uploads", filename)
```

This lets Python construct the filesystem path appropriately for the operating system.

```
import os

path = os.path.join(
    UPLOAD_FOLDER,
    filename
)
```

Then:

```
file.save(path)
```

# 18. Multiple File Upload

HTML can allow multiple files:

```
<input
    type="file"
    name="documents"
    multiple
>
```

Flask:

```
files = request.files.getlist("documents")
```

Now:

```
files
```

contains multiple uploaded file objects.

You can process them:

```
for file in files:

    if file.filename == "":
        continue

    filename = secure_filename(file.filename)

    file.save(
        os.path.join(
            "uploads",
            filename
        )
    )
```

The flow becomes:

```
User selects
file1.pdf
file2.pdf
file3.pdf
      ↓
POST
      ↓
request.files
      ↓
getlist()
      ↓
Loop through files
```

# 22. Don't Use the Original Filename as a Unique Identifier

Imagine two users upload:

```
profile.jpg
```

If you save both as:

```
uploads/profile.jpg
```

the second upload could overwrite the first.

A better approach is to generate a unique filename.

For example:

```
import uuid
```

Then:

```
extension = filename.rsplit(".", 1)[1].lower()

new_filename = f"{uuid.uuid4()}.{extension}"
```

Now the file might become something like:

```
8f1c...a92d.png
```

instead of:

```
profile.png
```

This avoids many filename collisions.

                      ▼

                      │

For larger applications, you may eventually store uploaded files in object storage rather than directly on the Flask server.

# 24. Should the File Go Into MySQL?

Usually, **not necessarily**.

There are two broad approaches.

### Store the actual file in filesystem/object storage

```
MySQL
 └── filename/path/metadata

Storage
 └── actual file
```

For example:

```
MySQL:
id = 10
filename = "abc123.pdf"
path = "uploads/abc123.pdf"
```

The actual PDF lives in storage.

### Store the binary file in the database

MySQL can store binary data using types such as:

```
BLOB
MEDIUMBLOB
LONGBLOB
```

But for many web applications, storing large files directly in the database is not the simplest architecture.

A common design is:

```
File
 ↓
Storage
 ↓
MySQL stores metadata
```

We'll revisit this when we reach **Flask + MySQL**.

# 25. File Upload and Security

File uploads deserve extra care because the server is accepting data that becomes part of its filesystem or storage system.

Important checks include:

### 1. Limit file size

```
app.config["MAX_CONTENT_LENGTH"] = ...
```

### 2. Restrict accepted file types

```
ALLOWED_EXTENSIONS = {...}
```

### 3. Don't trust the filename

Use:

```
secure_filename()
```

### 4. Generate unique names

For example:

```
uuid.uuid4()
```

### 5. Validate the actual content when necessary

Especially for images and documents.

### 6. Consider where files are served from

User-uploaded files should not automatically become executable server-side code.

### 7. Don't trust client-provided MIME types blindly

A request's `Content-Type` is supplied by the client and should not be treated as definitive proof of what the file contains.

# 26. File Upload vs File Download

Don't confuse these two.

### Upload

```
User
  ↓
Flask
```

The user sends a file **to your server**.

Flask:

```
request.files
```

### Download

```
Flask
  ↓
User
```

The server sends a file **to the user**.

Flask provides functions such as:

```
send_file()
```

or:

```
send_from_directory()
```

File download is a separate topic.

# 27. Complete Project Example

Project:

```
project/
│
├── app.py
│
├── uploads/
│
└── templates/
    └── upload.html
```

### `app.py`

```
from flask import Flask, request, render_template
from werkzeug.utils import secure_filename
import os
import uuid

app = Flask(__name__)

UPLOAD_FOLDER = "uploads"

app.config["MAX_CONTENT_LENGTH"] = 16 * 1024 * 1024

ALLOWED_EXTENSIONS = {
    "jpg",
    "jpeg",
    "png",
    "pdf"
}


def allowed_file(filename):

    return (
        "." in filename
        and filename.rsplit(".", 1)[1].lower()
        in ALLOWED_EXTENSIONS
    )


@app.route("/")
def home():

    return render_template("upload.html")


@app.route("/upload", methods=["POST"])
def upload():

    file = request.files.get("document")

    if not file or file.filename == "":
        return "No file selected"

    if not allowed_file(file.filename):
        return "File type not allowed"

    original_name = secure_filename(
        file.filename
    )

    extension = original_name.rsplit(
        ".",
        1
    )[1].lower()

    filename = f"{uuid.uuid4()}.{extension}"

    os.makedirs(
        UPLOAD_FOLDER,
        exist_ok=True
    )

    file.save(
        os.path.join(
            UPLOAD_FOLDER,
            filename
        )
    )

    return "File uploaded successfully"


if __name__ == "__main__":
    app.run(debug=True)
```
