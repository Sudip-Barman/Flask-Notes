# Custom Error Handlers (`@app.errorhandler`)

By default, Flask displays simple error pages like:

```
404 Not Found

The requested URL was not found on the server.
```

or

```
500 Internal Server Error
```

These pages are useful for developers but don't provide a great experience for users. Flask lets you replace them with your own custom pages.

---

# What is an Error Handler?

## Definition

An **error handler** is a function that Flask automatically calls whenever a specific HTTP error occurs.

> **Simple Definition:**
> 
> An error handler lets you create your own page for errors like 404, 403, or 500.

---

# Why Do We Need Error Handlers?

Imagine you're visiting an online shopping website.

Instead of seeing:

```
404 Not Found
```

you see:

```
Oops! 😔

The product you're looking for doesn't exist.

[ Go Back Home ]
```

This looks much more professional.

---

# Syntax

```
@app.errorhandler(status_code)
def function(error):
    ...
```

Example:

```
@app.errorhandler(404)
def not_found(error):
    return "Page Not Found"
```

---

# First Example

```
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Home"

@app.errorhandler(404)
def page_not_found(error):
    return "Oops! Page Not Found", 404

if __name__ == "__main__":
    app.run(debug=True)
```

Visit:

```
http://127.0.0.1:5000/abc
```

Output:

```
Oops! Page Not Found
```

Instead of Flask's default page.

---

# How It Works

```
Browser

↓

GET /abc

↓

No Matching Route

↓

404 Error

↓

@app.errorhandler(404)

↓

Custom Response

↓

Browser
```

---

# Why Return `404` Again?

Notice this:

```
return "Page Not Found", 404
```

Why not just write:

```
return "Page Not Found"
```

Because Flask would return:

```
200 OK
```

which is incorrect.

Always return the proper status code.

---

# Handling 403 Errors

```
from flask import abort

@app.route("/admin")
def admin():
    abort(403)

@app.errorhandler(403)
def forbidden(error):
    return "Access Denied", 403
```

Visit:

```
/admin
```

Output:

```
Access Denied
```

---

# Handling 500 Errors

```
@app.route("/test")
def test():
    return 10 / 0
```

Now create:

```
@app.errorhandler(500)
def server_error(error):
    return "Something went wrong!", 500
```

If the application crashes, Flask shows your custom page.

---

# Using the Error Object

The error handler receives an error object.

```
@app.errorhandler(404)
def not_found(error):
    return str(error), 404
```

Output:

```
404 Not Found:
The requested URL was not found on the server.
```

Usually, you won't display this to users, but it's useful for debugging.

---

# Custom HTML Error Page

Instead of returning plain text, return HTML.

```
@app.errorhandler(404)
def not_found(error):

    return """
    <h1>404</h1>
    <h2>Page Not Found</h2>
    <a href="/">Go Home</a>
    """, 404
```

Output:

```
404

Page Not Found

Go Home
```

---

# Using Templates

Most real applications use HTML templates.

Project:

```
project/

│── app.py

├── templates/

      ├──404.html

      ├──403.html

      └──500.html
```

Example:

```
from flask import render_template

@app.errorhandler(404)
def not_found(error):
    return render_template("404.html"), 404
```

Now Flask displays:

```
templates/404.html
```

---

# Handling Multiple Errors

```
@app.errorhandler(404)
def not_found(error):
    return "404 Error", 404

@app.errorhandler(403)
def forbidden(error):
    return "403 Error", 403

@app.errorhandler(500)
def server_error(error):
    return "500 Error", 500
```

Each error has its own handler.

---

# `abort()` + Error Handler

```
from flask import abort

@app.route("/student/<int:id>")
def student(id):

    if id != 1:
        abort(404)

    return "Student Found"
```

Flow:

```
/student/5

↓

abort(404)

↓

Error Handler

↓

Custom 404 Page
```

# Common Mistakes

## ❌ Forgetting the Status Code

Wrong:

```
return "Not Found"
```

Status:

```
200 OK
```

Correct:

```
return "Not Found", 404
```

---

## ❌ Wrong Error Code

```
@app.errorhandler(405)
```

This handles only:

```
405 Method Not Allowed
```

It does **not** handle 404 errors.

---

## ❌ Creating Multiple 404 Handlers

Wrong:

```
@app.errorhandler(404)
def first(error):
    ...

@app.errorhandler(404)
def second(error):
    ...
```

Only one handler should exist for each status code.

---

# Best Practices

✅ Create custom pages for:

- 404
- 403
- 500

---

✅ Return the correct status code.

```
return render_template("404.html"), 404
```

---

✅ Keep error pages simple and helpful.

Example:

```
404

Page Not Found

Return Home
```

---

✅ Use templates instead of long HTML strings.
