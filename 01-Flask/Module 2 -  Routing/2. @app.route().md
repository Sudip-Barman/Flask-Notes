# What is a Decorator?

## Definition

A **decorator** is a special Python feature that **adds extra functionality to a function without changing the function's original code**.

> **Simple Definition:**
> 
> A decorator "decorates" a function by giving it additional behavior.

---

# Real-Life Analogy

Imagine you buy a mobile phone.

```
Phone
```

You add a phone case.

```
Phone
   +
Case
```

The phone still works the same, but now it has extra protection.

A decorator works in a similar way.

```
Function
     +
Decorator
     =
Enhanced Function
```

---

# What Does `@app.route()` Do?

When you write:

```
@app.route("/")
def home():
    return "Home Page"
```

Flask understands:

> "Whenever someone visits `/`, execute the `home()` function."

The decorator **registers** the function with Flask's routing system.

---

# Behind the Scenes

The following code:

```
@app.route("/")
def home():
    return "Home"
```

is roughly equivalent to:

```
def home():
    return "Home"

app.route("/")(home)
```

You don't normally write it this way, but this is how Python applies decorators.

---

# How Flask Stores Routes

When Flask starts, every `@app.route()` is registered in an internal routing table.

Example:

```
@app.route("/")
def home():
    return "Home"

@app.route("/about")
def about():
    return "About"
```

Internally (conceptually):

|URL|Function|
|---|---|
|`/`|`home`|
|`/about`|`about`|

When a request arrives, Flask looks up the URL in this table and calls the matching function.

---

# Basic Syntax

```
@app.route(rule, **options)
```

The two most important parts are:

- `rule` → the URL pattern.
- `options` → additional settings like HTTP methods.

---

# Example

```
@app.route("/contact")
def contact():
    return "Contact Us"
```

If the user visits:

```
http://127.0.0.1:5000/contact
```

Flask executes:

```
contact()
```

and returns:

```
Contact Us
```

---

# Route Parameters

The `route()` decorator accepts several optional parameters.

## 1. `rule`

The URL to match.

```
@app.route("/")
```

```
@app.route("/about")
```

```
@app.route("/login")
```

---

## 2. `methods`

Specifies which HTTP methods are allowed.

Default:

```
@app.route("/")
```

Equivalent to:

```
@app.route("/", methods=["GET"])
```

Allow GET and POST:

```
@app.route("/login", methods=["GET", "POST"])
```

We'll explore this in detail later.

---

## 3. `endpoint`

Every route has an **endpoint name**.

Normally, Flask uses the function name.

```
@app.route("/")
def home():
    return "Home"
```

Endpoint:

```
home
```

You can customize it:

```
@app.route("/", endpoint="homepage")
def home():
    return "Home"
```

This is useful when generating URLs with `url_for()`.

---

# Multiple URLs for One Function

A single function can respond to multiple URLs.

```
@app.route("/")
@app.route("/home")
def home():
    return "Home Page"
```

Now both URLs work:

```
/
```

and

```
/home
```

# Multiple Decorators

Python allows multiple decorators.

Example:

```
@app.route("/")
@app.route("/index")
@app.route("/home")
def home():
    return "Welcome!"
```

All three URLs display the same page.

---

# Common Mistakes

### ❌ Forgetting the `@`

Wrong:

```
app.route("/")
def home():
    return "Home"
```

Without `@`, the decorator is never applied.

Correct:

```
@app.route("/")
def home():
    return "Home"
```

---

### ❌ Missing the Leading Slash

Wrong:

```
@app.route("about")
```

Correct:

```
@app.route("/about")
```

---

### ❌ Duplicate Routes

```
@app.route("/")
def home():
    ...

@app.route("/")
def index():
    ...
```

Avoid assigning two different functions to the same URL.
