# What is `abort()`?

## Definition

`abort()` immediately stops the execution of the current request and returns an HTTP error response.

> **Simple Definition:**
> 
> `abort()` tells Flask:  
> **"Stop here and send this error to the user."**

---

# Why Do We Need `abort()`?

Imagine an ATM.

```
Insert Card

↓

Enter PIN

↓

Wrong PIN
```

Should the ATM continue?

❌ No.

It immediately stops and shows:

```
Access Denied
```

Similarly, Flask uses `abort()` to stop processing when something is wrong.

---

# Syntax

```
from flask import abort
```

```
abort(status_code)
```

Example:

```
abort(404)
```

---

# First Example

```
from flask import Flask, abort

app = Flask(__name__)

@app.route("/")
def home():
    abort(404)

if __name__ == "__main__":
    app.run(debug=True)
```

Visit:

```
http://127.0.0.1:5000/
```

Output:

```
404 Not Found
```

The function stops immediately.

---

# How `abort()` Works

```
Browser

↓

GET /

↓

home()

↓

abort(404)

↓

Stop Execution

↓

Return Error Page
```

Notice:

Any code after `abort()` is **never executed**.

---

# Example

```
@app.route("/")
def home():

    print("Start")

    abort(404)

    print("End")

    return "Hello"
```

Output in terminal:

```
Start
```

Only `"Start"` prints.

Everything after `abort()` is skipped.

# Common HTTP Status Codes

|Code|Meaning|
|---|---|
|400|Bad Request|
|401|Unauthorized|
|403|Forbidden|
|404|Not Found|
|405|Method Not Allowed|
|500|Internal Server Error|

---

# `abort(404)`

Used when a resource doesn't exist.

Example:

```
@app.route("/product/<int:id>")
def product(id):

    if id != 1:
        abort(404)

    return "Product Found"
```

Visit:

```
/product/1
```

Output:

```
Product Found
```

Visit:

```
/product/10
```

Output:

```
404 Not Found
```

---

# `abort(403)`

Used when access is forbidden.

Example:

```
@app.route("/admin")
def admin():

    is_admin = False

    if not is_admin:
        abort(403)

    return "Admin Panel"
```

Output:

```
403 Forbidden
```

---

# `abort(401)`

Used when authentication is required.

Example:

```
@app.route("/profile")
def profile():

    logged_in = False

    if not logged_in:
        abort(401)

    return "Profile"
```

Output:

```
401 Unauthorized
```

---

# `abort(400)`

Used for invalid client requests.

Example:

```
@app.route("/calculate")
def calculate():

    number = None

    if number is None:
        abort(400)

    return "Success"
```

Output:

```
400 Bad Request
```

---

# `abort(500)`

Usually Flask generates this automatically when your application crashes.

You can also trigger it manually:

```
@app.route("/test")
def test():
    abort(500)
```

Output:

```
500 Internal Server Error
```

---

# Custom Error Messages

You can provide a description.

```
abort(
    404,
    description="Student not found"
)
```

If you later create a custom error handler, this description can be displayed to the user.

---

# Using `abort()` with Conditions

Example:

```
@app.route("/vote/<int:age>")
def vote(age):

    if age < 18:
        abort(403)

    return "You can vote."
```

Visit:

```
/vote/20
```

Output:

```
You can vote.
```

Visit:

```
/vote/15
```

Output:

```
403 Forbidden
```

# `abort()` vs `return`

### Using `return`

```
return "Product Not Found"
```

Browser receives:

```
200 OK
```

This is misleading because the request actually failed.

---

### Using `abort()`

```
abort(404)
```

Browser receives:

```
404 Not Found
```

This correctly indicates an error.

---

# Common Mistakes

## ❌ Forgetting to Import

Wrong:

```
abort(404)
```

Without:

```
from flask import abort
```

Result:

```
NameError:
abort is not defined
```

---

## ❌ Writing Code After `abort()`

```
abort(404)

return "Hello"
```

The `return` statement is unreachable because `abort()` stops execution.

---

## ❌ Returning Error Messages Instead of HTTP Errors

Bad:

```
return "Access Denied"
```

Status:

```
200 OK
```

Better:

```
abort(403)
```

Status:

```
403 Forbidden
```

---

# Best Practices

✅ Use `abort(404)` when a resource doesn't exist.

---

✅ Use `abort(403)` for permission issues.

---

✅ Use `abort(401)` when authentication is required.

---

✅ Use `abort(400)` for invalid client requests.

---

✅ Combine `abort()` with custom error pages for a better user experience.
