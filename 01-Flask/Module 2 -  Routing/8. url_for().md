# What is `url_for()`?

## Definition

`url_for()` is a Flask function that **generates a URL for a specific route** using its endpoint (function name).

> **Simple Definition:**
> 
> `url_for()` creates URLs automatically instead of you typing them manually.

---

# Why Do We Need `url_for()`?

Suppose you have this route:

```
@app.route("/about")
def about():
    return "About Page"
```

You could manually write:

```
<a href="/about">About</a>
```

It works.

But what happens if you later change the route?

```
@app.route("/about-us")
def about():
    return "About Page"
```

Your HTML still contains:

```
<a href="/about">About</a>
```

Now the link is broken.

❌ **404 Not Found**

---

Using `url_for()`:

```
<a href="{{ url_for('about') }}">About</a>
```

Flask automatically generates:

```
/about-us
```

You only change the route in one place, and every link updates automatically.

---

# Syntax

```
url_for(endpoint, **values)
```

Where:

- `endpoint` → Function name (not the URL)
- `values` → Variables for dynamic routes

---

# Basic Example

```
from flask import Flask, url_for

app = Flask(__name__)

@app.route("/")
def home():
    return url_for("about")

@app.route("/about")
def about():
    return "About Page"
```

Visit:

```
http://127.0.0.1:5000/
```

Output:

```
/about
```

Notice:

We passed:

```
url_for("about")
```

NOT

```
url_for("/about")
```

Because `url_for()` uses the **function name**, not the URL.

---

# How `url_for()` Works

```
Function Name

↓

url_for()

↓

Flask Routing Table

↓

Matching URL

↓

Generated URL
```

# Example

```
@app.route("/")
def home():
    return "Home"

@app.route("/about")
def about():
    return "About"
```

Route table:

|Function|URL|
|---|---|
|`home`|`/`|
|`about`|`/about`|

Calling:

```
url_for("about")
```

Returns:

```
/about
```

# Multiple Routes Example

```
from flask import Flask, url_for

app = Flask(__name__)

@app.route("/")
def home():
    return url_for("contact")

@app.route("/contact")
def contact():
    return "Contact"

@app.route("/about")
def about():
    return "About"
```

Output:

```
/contact
```

# `url_for()` with Dynamic Routes

Suppose we have:

```
@app.route("/user/<username>")
def user(username):
    return f"Hello {username}"
```

How can Flask generate this URL?

It needs the username.

So:

```
url_for("user", username="Sudip")
```

Returns:

```
/user/Sudip
```

---

Another example:

```
@app.route("/student/<int:id>")
def student(id):
    return f"Student {id}"
```

Generate:

```
url_for("student", id=101)
```

Result:

```
/student/101
```

---

# Multiple Variables

```
@app.route("/marks/<subject>/<int:score>")
def marks(subject, score):
    return f"{subject}: {score}"
```

Generate:

```
url_for(
    "marks",
    subject="Python",
    score=95
)
```

Result:

```
/marks/Python/95
```

---

# Using `url_for()` in HTML Templates

Most commonly, `url_for()` is used inside Jinja templates.

Example:

```
<a href="{{ url_for('home') }}">Home</a>

<a href="{{ url_for('about') }}">About</a>

<a href="{{ url_for('contact') }}">Contact</a>
```

Flask generates:

```
<a href="/">Home</a>

<a href="/about">About</a>

<a href="/contact">Contact</a>
```

---

# Using `url_for()` for Static Files

Suppose your CSS file is:

```
static/css/style.css
```

Instead of writing:

```
<link rel="stylesheet" href="/static/css/style.css">
```

Use:

```
<link rel="stylesheet"
      href="{{ url_for('static', filename='css/style.css') }}">
```

Flask generates:

```
/static/css/style.css
```

Similarly:

```
<img src="{{ url_for('static', filename='images/logo.png') }}">
```

Result:

```
/static/images/logo.png
```

# External URLs

Normally:

```
url_for("home")
```

Returns:

```
/
```

If you want the full URL:

```
url_for("home", _external=True)
```

Output:

```
http://127.0.0.1:5000/
```

Useful when:

- Sending emails
- Creating API links
- Redirecting across domains

# Common Mistakes

## ❌ Using the URL Instead of the Function Name

Wrong:

```
url_for("/about")
```

Correct:

```
url_for("about")
```

---

## ❌ Forgetting Dynamic Variables

Route:

```
@app.route("/user/<username>")
```

Wrong:

```
url_for("user")
```

Flask raises an error because `username` is required.

Correct:

```
url_for(
    "user",
    username="Sudip"
)
```

---

## ❌ Hardcoding URLs

Bad:

```
<a href="/contact">
```

Better:

```
<a href="{{ url_for('contact') }}">
```

---

# Best Practices

✅ Always use `url_for()` instead of hardcoded URLs.

---

✅ Use function names as endpoints.

```
url_for("login")
```

Not:

```
url_for("/login")
```

---

✅ Use `url_for()` for static files.

```
url_for(
    "static",
    filename="css/style.css"
)
```

---

✅ Pass all required variables for dynamic routes.

```
url_for(
    "product",
    id=25
)
```
