# Redirect (`redirect()`)

Sometimes, instead of sending a page directly, we want Flask to tell the browser:

> **"Don't stay here. Go to another URL."**

This is called a **redirect**.

---

# What is Redirect?

## Definition

A **redirect** is an HTTP response that tells the browser to automatically visit a different URL.

> **Simple Definition:**
> 
> A redirect sends the user from one URL to another.

---

# Why Do We Need Redirects?

Imagine a website where the login page is:

```
/login
```

After a successful login, should the user stay on `/login`?

❌ No.

Instead, send them to:

```
/dashboard
```

This is a redirect.

---

# Real-Life Analogy

Imagine you're looking for Room 101.

You arrive at Room 101, but there's a sign:

```
Room shifted to 205

↓

Go to Room 205
```

You don't stay there.

You go to the new room.

A redirect works exactly like that.

---

# Syntax

```
from flask import redirect
```

```
redirect(location)
```

---

# First Example

```
from flask import Flask, redirect

app = Flask(__name__)

@app.route("/")
def home():
    return redirect("/about")

@app.route("/about")
def about():
    return "About Page"

if __name__ == "__main__":
    app.run(debug=True)
```

Visit:

```
http://127.0.0.1:5000/
```

Flask sends:

```
Redirect

↓

/about
```

Browser automatically opens:

```
http://127.0.0.1:5000/about
```

Output:

```
About Page
```

---

# How Redirect Works

```
Browser

↓

GET /

↓

Flask

↓

redirect("/about")

↓

HTTP Response (302)

↓

Browser

↓

GET /about

↓

About Page
```

Notice:

The browser actually makes **two requests**.

---

# Using `redirect()` with `url_for()` ⭐ (Recommended)

Instead of writing:

```
return redirect("/about")
```

Write:

```
from flask import redirect, url_for

return redirect(url_for("about"))
```

Complete example:

```
from flask import Flask, redirect, url_for

app = Flask(__name__)

@app.route("/")
def home():
    return redirect(url_for("about"))

@app.route("/about")
def about():
    return "About Page"
```

Why?

Suppose later you change:

```
@app.route("/about-us")
def about():
    return "About Page"
```

Because you're using:

```
url_for("about")
```

Flask automatically redirects to:

```
/about-us
```

No other code needs to change.

---

# Redirect with Dynamic Routes

Example:

```
@app.route("/profile/<username>")
def profile(username):
    return f"Profile of {username}"

@app.route("/login")
def login():
    return redirect(
        url_for(
            "profile",
            username="Sudip"
        )
    )
```

Visit:

```
/login
```

Browser redirects to:

```
/profile/Sudip
```

Output:

```
Profile of Sudip
```

---

# Redirect Flow

```
/login

↓

login()

↓

redirect()

↓

url_for()

↓

/profile/Sudip

↓

Browser

↓

GET /profile/Sudip

↓

profile()

↓

Response
```

# Redirect Status Codes

Whenever Flask redirects, it sends an HTTP status code.

The most common ones are:

|Status Code|Meaning|
|---|---|
|**302**|Temporary Redirect (Default)|
|**301**|Permanent Redirect|
|**307**|Temporary Redirect (Preserves HTTP Method)|
|**308**|Permanent Redirect (Preserves HTTP Method)|

---

# Default Redirect (302)

```
return redirect(url_for("home"))
```

Equivalent to:

```
return redirect(
    url_for("home"),
    code=302
)
```

---

# Permanent Redirect (301)

```
return redirect(
    url_for("home"),
    code=301
)
```

Useful when a page has permanently moved.

Example:

```
/old-about

↓

/about
```

Search engines update their records.

---

# Temporary vs Permanent

### 302

```
Old URL

↓

Temporary

↓

Browser remembers old URL
```

---

### 301

```
Old URL

↓

Permanent

↓

Search engines update

↓

Browser may cache it
```

# Common Mistakes

## ❌ Returning a String Instead of Redirecting

Wrong:

```
@app.route("/")
def home():
    return "/about"
```

Output:

```
/about
```

The browser displays the text.

It **does not** visit `/about`.

---

Correct:

```
return redirect("/about")
```

---

## ❌ Hardcoding URLs

Bad:

```
redirect("/profile")
```

Better:

```
redirect(url_for("profile"))
```

---

## ❌ Forgetting to Import

Wrong:

```
return redirect(...)
```

Without:

```
from flask import redirect
```

Python raises:

```
NameError:
redirect is not defined
```

---

# Best Practices

✅ Always combine `redirect()` with `url_for()`.

```
redirect(url_for("home"))
```

---

✅ Use redirects after successful form submissions.

---

✅ Use `301` only for permanent URL changes.

---

✅ Keep redirect chains short.

Bad:

```
A

↓

B

↓

C

↓

D
```

Good:

```
A

↓

D
```
