# What is an HTTP Method?

## Definition

An **HTTP Method** (also called an **HTTP Verb**) tells the server **what action the client wants to perform** on a resource.

> **Simple Definition:**
> 
> An HTTP method is the **type of request** sent from the client to the server.

---

# Why Do We Need HTTP Methods?

Imagine a library.

You can:

- Read a book 📖
- Add a new book 📚
- Update book information ✏️
- Remove a book 🗑️

Each action is different.

Similarly, websites and APIs perform different actions using different HTTP methods.

---

# Client-Server Communication

```
Browser

↓

HTTP Request

↓

Method + URL

↓

Flask Server

↓

Response

↓

```

Example:

```
GET /about
```

The browser is saying:

> "Please give me the About page."

---

# Common HTTP Methods

|Method|Purpose|
|---|---|
|GET|Retrieve data|
|POST|Send new data|
|PUT|Replace existing data|
|PATCH|Update part of existing data|
|DELETE|Remove data|

These five methods are the ones you'll use most often.

---

# 1. GET Method

## Definition

The **GET** method requests data from the server.

It **does not change** any data.

---

### Real-Life Example

Searching Google:

```
https://google.com/search?q=python
```

The browser is asking:

> "Give me search results."

---

### Flask Example

```
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Welcome!"
```

This route automatically accepts:

```
GET /
```

because GET is the default HTTP method.

---

### Browser Request

```
GET /
```

Server Response:

```
Welcome!
```

---

# GET Flow

```
Browser

↓

GET /

↓

Flask

↓

home()

↓

Return HTML

↓

```

# 2. POST Method

## Definition

The **POST** method sends new data to the server.

Examples:

- Login form
- Registration form
- Uploading a file
- Creating a new blog post

---

### Flask Example

```
from flask import request

@app.route("/login", methods=["POST"])
def login():
    username = request.form["username"]
    return f"Welcome {username}"
```

The client sends data:

```
username = Sudip
```

The server receives it and processes it.

---

# POST Flow

```
Browser

↓

POST /login

↓

username=Sudip

↓

Flask

↓

request.form

↓

Response
```

# 3. PUT Method

## Definition

The **PUT** method **replaces** an existing resource.

Imagine updating an entire student record.

Old record:

```
Name: Rahul

Age: 20

City: Delhi
```

New record:

```
Name: Rahul

Age: 21

City: Mumbai
```

Everything is replaced.

---

### Flask Example

```
@app.route("/student/<int:id>", methods=["PUT"])
def update_student(id):
    return f"Student {id} updated"
```

---

# 4. PATCH Method

## Definition

PATCH updates **only part** of a resource.

Example:

Current student:

```
Name: Rahul

Age: 20

City: Delhi
```

Only change the city:

```
City: Mumbai
```

Everything else stays the same.

---

### Flask Example

```
@app.route("/student/<int:id>", methods=["PATCH"])
def patch_student(id):
    return f"Student {id} partially updated"
```

---

# PUT vs PATCH

Suppose we have:

```
Student

Name
Age
City
Email
```

PUT

```
Replace Everything
```

PATCH

```
Replace Only Selected Fields
```

|PUT|PATCH|
|---|---|
|Entire resource|Partial resource|
|Replace all fields|Replace selected fields|
|Larger request|Smaller request|

---

# 5. DELETE Method

## Definition

Deletes a resource.

Example:

Delete student:

```
Student ID 25

↓

Removed
```

---

### Flask Example

```
@app.route("/student/<int:id>", methods=["DELETE"])
def delete_student(id):
    return f"Student {id} deleted"
```

# Using `methods` in Flask

Default:

```
@app.route("/")
```

Equivalent to:

```
@app.route("/", methods=["GET"])
```

Allow GET and POST:

```
@app.route("/login", methods=["GET", "POST"])
def login():
    return "Login"
```

Flask now accepts:

```
GET /login
```

and

```
POST /login
```

---

# Multiple Methods

```
@app.route("/profile", methods=["GET", "POST"])
def profile():
    return "Profile"
```

This single route can handle both methods.

# Checking the Request Method

Flask provides the `request` object.

```
from flask import request
```

Example:

```
from flask import Flask, request

app = Flask(__name__)

@app.route("/login", methods=["GET", "POST"])
def login():

    if request.method == "GET":
        return "Login Form"

    if request.method == "POST":
        return "Processing Login"

if __name__ == "__main__":
    app.run(debug=True)
```

# Common Mistakes

## ❌ Forgetting to Allow POST

```
@app.route("/login")
```

Then sending:

```
POST /login
```

Result:

```
405 Method Not Allowed
```

---

Correct:

```
@app.route("/login", methods=["POST"])
```

or

```
@app.route("/login", methods=["GET", "POST"])
```

---

## ❌ Using GET for Sensitive Data

Bad:

```
/login?password=123456
```

The password appears in the URL.

Use POST instead.

---

## ❌ Confusing PUT and PATCH

PUT

```
Replace Entire Object
```

PATCH

```
Update Selected Fields
```

---

# Best Practices

✅ Use **GET** for reading data.

```
/products
```

---

✅ Use **POST** for creating new data.

```
/register
```

---

✅ Use **PUT** for replacing an existing resource.

```
PUT /student/10
```

---

✅ Use **PATCH** for updating only some fields.

```
PATCH /student/10
```

---

✅ Use **DELETE** for removing resources.

```
DELETE /student/10
```

|---|---|---|---|

|PATCH|Partial Update|✅ Yes|Change email|
