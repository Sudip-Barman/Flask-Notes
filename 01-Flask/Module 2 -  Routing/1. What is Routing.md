
# Definition

**Routing** is the process of mapping a **URL** (Uniform Resource Locator) to a **Python function**.

When a client requests a URL, Flask searches its routing table and executes the corresponding function.

> **Simple Definition:**
> 
> A route tells Flask **which function to execute when a specific URL is requested.**

---

# Why Do We Need Routing?

Imagine a website without routing.

```
Website

Home
About
Contact
Login
Profile
Products
```

If Flask didn't have routing, it wouldn't know:

- Which page to open
- Which function to execute
- Which data to return

Routing solves this problem.

# Basic Syntax

```
@app.route("/url")
def function_name():
    return "Response"
```

General syntax:

```
@app.route("URL")
def function():
    return Response
```

---

# Example

```
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Home Page"

@app.route("/about")
def about():
    return "About Page"

@app.route("/contact")
def contact():
    return "Contact Page"

if __name__ == "__main__":
    app.run(debug=True)
```

# How Flask Finds the Correct Function

Suppose the user enters:

```
http://127.0.0.1:5000/about
```

Flask performs these steps:

```
Request Received

↓

Read URL

↓

Search Routing Table

↓

Found "/about"

↓

Execute about()

↓

Return Response

↓

Browser Displays Page
```

---

# Route Table (Conceptual)

Internally, Flask maintains a routing table similar to:

|URL|Function|
|---|---|
|`/`|`home()`|
|`/about`|`about()`|
|`/contact`|`contact()`|

When a request arrives, Flask searches this table.

---

# URL Rules

A URL always starts with a forward slash (`/`).

Correct:

```
@app.route("/")
```

```
@app.route("/about")
```

```
@app.route("/products")
```

Incorrect:

```
@app.route("about")
```

❌ Missing leading `/`

---

# Route Naming Best Practices

Good:

```
/about
/contact
/products
/services
/profile
```

Avoid:

```
/page1
/page2
/test
/abc
```

Routes should clearly describe their purpose.

# Multiple Routes

A Flask application can have as many routes as needed.

Example:

```
@app.route("/")
def home():
    return "Home"

@app.route("/about")
def about():
    return "About"

@app.route("/contact")
def contact():
    return "Contact"

@app.route("/login")
def login():
    return "Login"

@app.route("/register")
def register():
    return "Register"
```

# Common Mistakes

### ❌ Missing Slash

Wrong:

```
@app.route("about")
```

Correct:

```
@app.route("/about")
```

---

### ❌ Duplicate Routes

Wrong:

```
@app.route("/")
def home():
    return "Home"

@app.route("/")
def index():
    return "Index"
```

Only one route should handle a specific URL.

---

### ❌ Forgetting `return`

Wrong:

```
@app.route("/")
def home():
    print("Hello")
```

The browser receives nothing because `print()` writes to the terminal.

Correct:

```
@app.route("/")
def home():
    return "Hello"
```
